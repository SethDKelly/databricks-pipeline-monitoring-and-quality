# OPS-055 — Localization Traversal, Semantic Scope & Topology Limits

**Status:** Accepted — Phase 007 Group 05

## Purpose

Use OPS-001–OPS-009 topology for investigation localization while preventing traversal mechanics from becoming causal ranking.

## Contract

Localization traversal binds:

- exact Investigation outcome/question;
- direction and relationship families/roles;
- event/effective time and knowledge cut;
- field/key/population/interface/consumer/version scope;
- bounded depth/path criteria;
- evidence and authorization limitations.

Operational relevance from OPS-007 determines whether a relationship is relevant to the localization question. Mere reachability is insufficient.

Traversal may stop because a sufficient explanatory boundary was found for the operational question, because the authorized/covered evidence boundary was reached, or because further relevance is indeterminate. None means the stop point is a root cause.

## Invariants

- reachable ≠ relevant ≠ causal.
- shortest path ≠ best explanation.
- nearest upstream deviation ≠ cause.
- repository/Monitoring Scope boundary ≠ causal boundary.
- missing intermediate granularity can make localization indeterminate.
- no universal graph-search/ranking rule is accepted.
