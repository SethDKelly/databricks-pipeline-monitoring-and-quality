# OPS-090 — Activation, Enforcement & Material Path Control

**Status:** Accepted — Phase 007 Group 07

## Purpose

Specialize REF-027 so `active safeguard` means evidence-backed protection on the exact material path/opportunity rather than an administrative record.

## Contract

For a bounded protection proposition distinguish:

1. activation/request evidence;
2. external/control-plane acceptance where applicable;
3. effective enforcement state;
4. the path/opportunity actually constrained;
5. resulting publication/consumption behavior.

Enforcement can be established independently for each relevant path, consumer set or interval.

## Invariants

- request/configuration ≠ enforcement.
- enforcement at path P ≠ enforcement at alternate path Q.
- enforcement ≠ prevented exposure without REF-028 conditions.
- no observed exposure ≠ enforcement proof.
- external-control telemetry conflict/unavailability remains explicit.
