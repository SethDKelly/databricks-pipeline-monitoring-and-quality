# EXPL-086 — Restricted, Redacted and Opaque Language

**Status:** Accepted — Phase 008 Group 05

## Requirement

`Restricted` means relevant state/evidence exists or may exist but disclosure/access is constrained; it is not equivalent to unavailable, absent or unresolved.

A safe Explanation may state that restricted context limits the answer when that meta-fact itself is authorized. Redaction/omission must never be worded as nonexistence.

The actual projection and basis-inspection rules are Group 06 work.
