# EXPL-081 — Epistemic State and Language Preservation

**Status:** Accepted — Phase 008 Group 05

## Requirement

Explanation wording must preserve the source proposition's actual epistemic/evidence state rather than translate every limitation into generic uncertainty.

At minimum preserve when material: supported/established positive conclusion, unknown/unresolved, unavailable, insufficient evidence/indeterminate, conflicting, restricted, stale-for-use, non-comparable, not applicable, not evidenced/not recorded, and evidence-backed negative conclusion.

## Boundary

These are communication mappings over source-owned states. EXPL-081 creates no universal epistemic state machine and no confidence score.
