# EXPL-084 — Insufficient Evidence / Indeterminate Language

**Status:** Accepted — Phase 008 Group 05

## Requirement

When applicable evidence exists but does not meet the conclusion-specific sufficiency burden, communicate `insufficient evidence` or the source concept's bounded `indeterminate` state.

This differs from no relevant evidence, unavailable evidence, contradiction, non-applicability and negative evidence.

Near-threshold measurement uncertainty, partial path coverage and incomplete lifecycle evidence must not be narrated as weak positive/negative conclusions merely for usefulness.
