# EXPL-085 — Conflict and Disagreement Language

**Status:** Accepted — Phase 008 Group 05

## Requirement

Applicable unresolved conflicts must remain explicit. Explain what propositions/sources disagree and whether an accepted authority/resolution rule actually resolves the relevant target.

Evidence conflict, authoritative assertion conflict, authority-rule conflict, authorization conflict and competing Causal Claims are not one generic conflict class.

No majority vote, newest-source, most-specific-source or prose winner is introduced.
