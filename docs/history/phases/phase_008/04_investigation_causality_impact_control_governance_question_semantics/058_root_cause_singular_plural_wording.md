# EXPL-058 — `Root Cause` Singular/Plural Wording Discipline

**Status:** Accepted — Phase 008 Group 04

## Requirement

Treat `root cause` as requested causal wording, not a special truth state.

A singular root-cause answer is permitted only when the accepted causal evidence/status actually supports the singular proposition under the governing scope.

Otherwise Explanation may report multiple supported contributors/causes, unresolved competing claims, or no confirmed cause.

The product does not force one winner merely because the user used the singular phrase.
