# EXPL-076 — Classification & Criticality Question

**Status:** Accepted — Phase 008 Group 04

## Requirement

Questions about sensitivity/category/criticality bind the named Classification scheme/context/time and its authority standing.

Classification may inform priority or policy applicability reasoning, but it is not itself Policy Context, authorization, health, exposure, consequence, severity or compliance.

Missing classification is `unknown`, not `non-sensitive`/low criticality; multiple schemes can legitimately coexist.
