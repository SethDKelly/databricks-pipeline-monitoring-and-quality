# EXPL-068 — Safeguard Release, Recovery & Control-Effect Question

**Status:** Accepted — Phase 008 Group 04

## Requirement

Questions about `was the quarantine lifted?`, `are we recovered?`, or `did protection cause staleness/delay?` decompose.

Release request ≠ effective release; release ≠ healthy/fresh/current/recovered state. Post-release recovery is independently observed/assessed.

Broader claims that Safeguard behavior caused delay, stale serving, non-delivery or business effect are Causal Claims; control overlap/timing alone is not attribution.
