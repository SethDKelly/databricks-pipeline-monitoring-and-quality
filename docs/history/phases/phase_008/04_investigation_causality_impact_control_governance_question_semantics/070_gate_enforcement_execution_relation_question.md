# EXPL-070 — Gate Enforcement & Execution-Relation Question

**Status:** Accepted — Phase 008 Group 04

## Requirement

Preserve decision issuance/delivery/acceptance/effective enforcement and actual execution separately.

HOLD ≠ failed execution. `No run` supports an enforced HOLD only with sufficient opportunity/execution coverage. A reliable run start during an applicable unsuperseded HOLD can contradict full enforcement.

ADMIT means this Gate barrier was removed/permissive; it does not prove a run occurred or that the Gate caused the run.
