# EXPL-012 — Group 02 Answer-Composition Handoff

**Status:** Accepted — Phase 008 Group 01

## Requirement

Define the stable input that Group 02 receives after a business question has been bounded.

For each question/subquestion, Group 02 receives as applicable:

- bounded question/request identity;
- requested conclusion type/family;
- resolved subject(s) plus unresolved identity ambiguity;
- explicit scope dimensions;
- event/effective-time target/window;
- knowledge-cut/current-retrospective perspective;
- requester/purpose/audience context known so far;
- truth-owner routing targets;
- material ambiguity/underspecification;
- answerability limitations already evident;
- negative-evidence burden where the requested conclusion is negative;
- provenance of any explicit contextual/default interpretation used.

## Handoff boundary

Group 02 may decide which material statements belong in the answer and how they trace to basis. It may not silently change the question scope, temporal perspective, truth owner or evidence burden to make composition easier.

If answer construction reveals a materially different interpretation, the question contract must remain traceable to that interpretation rather than being invisibly rewritten.

## Exit statement

EXPL-001–EXPL-012 provide sufficient question semantics for answer-structure refinement without introducing a new Question concept.
