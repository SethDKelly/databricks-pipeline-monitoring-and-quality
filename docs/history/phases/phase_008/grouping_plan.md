# Phase 008 Grouping Decision Summary

**Status:** Accepted planning artifact

Phase 008 is decomposed into eight dependency-ordered functional design groups:

1. Question Proposition, Intent, Scope & Temporal Perspective.
2. Answer Structure, Statement Selection & Basis Traceability.
3. Health, Change & Execution Question Semantics.
4. Investigation, Causality, Impact, Control & Governance Question Semantics.
5. Uncertainty, Conflict, Negative Claims & Epistemic Language.
6. Audience, Authorization, Safe Abstraction & Basis Inspection.
7. Progressive Maturity, Partial Answers, Refresh & Retention.
8. Historical/Comparative Explanation & Consolidation / Exit Review.

Phase 008 uses `EXPL-###` refinement contracts. The namespace refines the existing Explanation concept and its initiating question/request context; it does not create an `Answer` or `Question` concept by naming convention.

The grouping is intentionally functional and implementation-neutral. It does not imply UI surfaces, APIs, services, prompt chains, LLM agents, templates, retrieval stores, vector indexes, persistence boundaries or report-generation architecture.
