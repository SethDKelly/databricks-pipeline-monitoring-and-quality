# EXPL-103 — Statement, Context & Limitation Visibility Separation

**Status:** Accepted — Phase 008 Group 06

## Requirement

Authorize answer-bearing conclusions, contextual statements and material limitations independently where policy requires.

A viewer may be permitted to receive `completeness degraded` while an exact threshold, restricted field identity, consumer identity or causal detail is hidden. Conversely, hiding a limitation is not permitted when doing so would strengthen the visible conclusion.

Presentation role does not itself grant visibility; each material information class remains governed by Capability Authorization/disclosure rules.
