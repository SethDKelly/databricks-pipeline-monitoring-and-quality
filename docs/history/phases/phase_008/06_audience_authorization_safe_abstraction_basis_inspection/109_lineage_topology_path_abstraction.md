# EXPL-109 — Lineage, Topology & Path Abstraction

**Status:** Accepted — Phase 008 Group 06

## Requirement

Lineage projection may hide node names, edge details, path segments, consumer identities or topology structure while retaining only an authorized proposition such as `a restricted upstream dependency exists` or `additional restricted downstream context limits exposure coverage`.

A redacted path does not prove a direct edge, unique path, full topology coverage, exposure or causality. Opaque topology cannot be summarized as absence.
