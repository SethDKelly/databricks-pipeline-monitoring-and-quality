# EXPL-111 — Material Limitation Visibility Under Redaction

**Status:** Accepted — Phase 008 Group 06

## Requirement

If a restricted/opaque item materially limits the visible conclusion, the authorized projection must preserve an allowed limitation at an appropriate abstraction level whenever a stronger unqualified statement would mislead.

The limitation need not reveal the hidden item. It may state, for example, `restricted evidence limits causal resolution` or `additional restricted consumer context prevents a global non-exposure conclusion` when those coarse disclosures are themselves authorized.

If even that acknowledgment is not authorized, the visible answer must narrow or withhold the affected conclusion rather than overstate it.
