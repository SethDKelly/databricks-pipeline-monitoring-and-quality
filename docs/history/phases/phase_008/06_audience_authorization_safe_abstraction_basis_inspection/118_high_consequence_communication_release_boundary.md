# EXPL-118 — High-Consequence Communication & Release Boundary

**Status:** Accepted — Phase 008 Group 06

## Requirement

Consume AUTH-049 where a communication class requires separate compose/review/approve/release/correct/retract authority.

Permission to internally view or compose a valid conclusion does not imply permission to publish a client-facing, regulatory-adjacent, causal-confirmation or other governed statement. Communication review/approval controls release of the Explanation; it does not change evidence sufficiency, causal status, health, compliance or control truth.
