# EXPL-119 — Historical State, Historical Access & Current Disclosure

**Status:** Accepted — Phase 008 Group 06

## Requirement

Keep separately answerable:

- what source/derived state existed or was known historically;
- what an historical actor was authorized to inspect/disclose then;
- what a retained historical Explanation actually communicated;
- and what the current requester is authorized to receive now.

Historical access does not grant current access, and current access is not projected backward. A present `as-known-then` Explanation still uses current disclosure authorization for the requester.
