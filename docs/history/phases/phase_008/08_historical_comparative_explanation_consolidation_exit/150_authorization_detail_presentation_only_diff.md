# EXPL-150 — Authorization, Detail & Presentation-Only Diffs

**Status:** Accepted — Phase 008 Group 08

A later Explanation can show more or less detail without any source-truth or epistemic change.

Newly visible evidence, newly hidden identity, different safe abstraction, citation visibility, ordering or wording are labeled as projection/presentation changes when the proposition/status is unchanged.

`More detailed` does not mean `more true`; `less visible` does not mean `less supported`.
