# EXPL-145 — Current Retrospective Interpretation

**Status:** Accepted — Phase 008 Group 08

A current retrospective Explanation evaluates a historical proposition using currently accepted evidence, corrections, authority and derivation rules appropriate to that historical event/effective scope.

It is not the same as what was known at incident time and not the same as what was communicated then.

Later evidence may establish, weaken or reverse the current retrospective conclusion without rewriting either earlier knowledge or retained communication.
