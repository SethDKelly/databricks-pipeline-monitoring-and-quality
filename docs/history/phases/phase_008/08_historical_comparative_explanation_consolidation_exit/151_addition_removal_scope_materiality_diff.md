# EXPL-151 — Addition, Removal, Scope & Materiality Diffs

**Status:** Accepted — Phase 008 Group 08

Statement addition/removal across Explanation views preserves the reason when knowable.

Possible reasons include newly material proposition, changed question scope, newly available evidence, source-state change, newly authorized disclosure, newly restricted disclosure, correction/supersession or presentation restructuring.

Removed from a view does not by itself mean false, resolved, retracted or nonexistent.
