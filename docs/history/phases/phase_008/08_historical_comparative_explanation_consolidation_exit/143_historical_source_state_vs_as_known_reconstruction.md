# EXPL-143 — Historical Source State vs As-Known Reconstruction

**Status:** Accepted — Phase 008 Group 08

Historical source-owned facts and an `as-known-at-K` Explanation are different objects.

The source fact may have been true/effective even when it was unknown at the selected knowledge cut. Conversely, an earlier interpretation may later be corrected without erasing the historical source action/state that actually occurred.

`Not known by K` is therefore not a statement that the real-world event did not occur.
