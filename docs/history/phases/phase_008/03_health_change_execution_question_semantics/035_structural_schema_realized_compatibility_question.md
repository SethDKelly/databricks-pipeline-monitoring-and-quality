# EXPL-035 — Structural Schema, Realized State & Compatibility Question

**Status:** Accepted — Phase 008 Group 03

## Requirement

Schema questions distinguish governed meaning/contract, proposed structural state, realized structural Observation/Change, and compatibility Assessment.

## Rules

- `what schema exists?` may project realized structural Observation;
- `what changed in the schema?` routes to realized Change plus structural evidence;
- `is the schema compatible?` routes to the exact consumer/interface compatibility Assessment;
- proposed compatibility ≠ realized compatibility;
- engine cast capability ≠ compatibility;
- compatible ≠ statistically comparable ≠ quality-meeting ≠ downstream success.

Consumer/version scope remains explicit where compatibility differs.
