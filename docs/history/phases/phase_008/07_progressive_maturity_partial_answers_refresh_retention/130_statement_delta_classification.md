# EXPL-130 — Statement Delta Classification

**Status:** Accepted — Phase 008 Group 07

Explanation-to-Explanation comparison may classify a material statement as:

- unchanged proposition/status;
- wording/presentation-only change;
- basis-enriched or basis-limited without conclusion change;
- epistemic/status revised by source truth;
- scope/temporal proposition changed;
- newly material/added;
- no longer material/removed from current composition;
- newly visible or newly restricted because authorization changed.

These are descriptive delta classes, not a lifecycle state machine or quality score.
