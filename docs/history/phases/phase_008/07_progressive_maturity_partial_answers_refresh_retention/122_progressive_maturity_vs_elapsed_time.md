# EXPL-122 — Progressive Evidence Maturity ≠ Elapsed Time

**Status:** Accepted — Phase 008 Group 07

Explanation maturity changes only when material source truth, evidence availability/applicability/sufficiency, derivation basis, authorization, or question/materiality context changes.

Elapsed time, polling frequency, repeated composition, model retries, additional prose, or a later generation timestamp do not strengthen an epistemic state by themselves.

A later Explanation may therefore be equally mature, less informative because authorization narrowed, or materially revised rather than automatically better/more certain.
