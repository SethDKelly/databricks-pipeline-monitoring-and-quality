# Phase 008 Group 07 — Progressive Maturity, Partial Answers, Refresh & Retention

**Status:** Review complete — accepted

## Goal

Refine partial and progressively maturing Explanation, stable-versus-revised statements, refresh triggers, retained snapshots, supersession/linkage and communication of new evidence without rewriting prior answers or implying elapsed time strengthens truth.

## Group result

Group 07 accepts **EXPL-121–EXPL-140** and **PMR07-01–PMR07-44**.

No new concept is required. Explanation already owns composed/retained communication; source concepts own truth and Capability Authorization owns current visible projection permission.

The accepted evolution chain is:

**bounded current question/subquestions → earliest trustworthy partial authorized answer → stable proposition/basis identity → material source/evidence/authorization change → proposition-specific re-evaluation → statement/projection delta classification → refreshed current Explanation → retained predecessor/supersession linkage → Group 08 historical/comparative handoff**.

No arrow treats time, recomposition or persistence as evidence.

## Accepted contracts

- **EXPL-121–EXPL-125** — partial answer eligibility, maturity versus elapsed time, stable identity, material refresh and no-op recomposition.
- **EXPL-126–EXPL-129** — basis enrichment, contradiction/conflict, correction/supersession and derived dependency re-evaluation.
- **EXPL-130–EXPL-133** — statement delta classes, addition/removal/materiality, authorization-driven projection change and question/scope lineage boundaries.
- **EXPL-134–EXPL-139** — retained actual communication, non-overwriting refresh linkage, prior snapshot versus current truth, partial-coverage evolution, change-summary semantics and retained-versus-reconstructible history.
- **EXPL-140** — Group 08 handoff.

## Durable rules

- a narrow trustworthy partial answer is valid; unresolved siblings remain explicit;
- partial answer coverage is proposition bound, not a completeness percentage;
- progressive maturity requires material evidence/source/authorization/context change; elapsed time is not evidence;
- repeated recomposition or new wording over unchanged semantics is not maturation;
- statement proposition identity survives wording/detail/basis-visibility changes when scope/time identity is unchanged;
- changed subject/scope/event window/knowledge cut is a different proposition, not a silent status update;
- basis can enrich without changing conclusion/status;
- contradiction/correction changes Explanation only through source-owned re-evaluation;
- derived statements re-evaluate their exact dependencies/join logic rather than transitively flipping;
- statement deltas distinguish presentation-only, basis-only, status, scope, materiality and authorization changes;
- removed from current projection ≠ false/retracted/nonexistent by default;
- authorization broadening/narrowing changes visibility, not internal truth;
- retained snapshot is evidence of actual prior communication, not timeless source truth;
- current source correction does not rewrite prior retained communication;
- a refreshed current Explanation may supersede prior use while retaining predecessor history;
- missing retained snapshots remain missing; reconstructed historical Explanation is not exact prior communication;
- current/retained/reconstructed views do not create a scalar maturity/confidence/quality score;
- change summaries may describe exact source transitions but cannot invent stronger epistemic language.
