# EXPL-134 — Retained Snapshot = Actual Communication Evidence

**Status:** Accepted — Phase 008 Group 07

A retained Explanation snapshot represents what was actually composed/communicated for its bound audience/projection context at that generation/release point.

It is evidence of prior communication, not a timeless copy of source truth. Current source state, current retrospective interpretation and current authorization may all differ.

If no retained or otherwise evidenced prior Explanation exists, the framework must not claim exact historical wording/communication from reconstruction alone.
