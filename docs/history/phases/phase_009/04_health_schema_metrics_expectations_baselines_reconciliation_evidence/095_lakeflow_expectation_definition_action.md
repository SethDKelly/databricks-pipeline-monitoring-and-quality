# INTG-095 — Lakeflow Expectation Definition & Action

**Status:** Accepted — Phase 009 Group 04

Lakeflow pipeline expectations define named SQL-boolean record constraints with warn, drop or fail-update behavior on supported streaming tables/materialized views/views.

An expectation can implement a governed framework criterion only when exact rule identity/version/authority/applicability are established. Its configured action remains separate from criterion truth, severity and downstream control policy.
