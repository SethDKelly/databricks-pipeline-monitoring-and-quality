# INTG-117 — Missing Metric / Check / Schema Negative Claims

**Status:** Accepted — Phase 009 Group 04

`no schema change`, `no failed check`, `no anomaly`, `no metric result`, `no quality issue` and similar negatives require the exact expected opportunity plus sufficient source/query/population/history coverage and source health.

A disabled profile, skipped intelligent scan, unsupported expectation flow, expired history, permission filtering, failed DQX run or absent instrumentation remains a limitation rather than a clean negative.
