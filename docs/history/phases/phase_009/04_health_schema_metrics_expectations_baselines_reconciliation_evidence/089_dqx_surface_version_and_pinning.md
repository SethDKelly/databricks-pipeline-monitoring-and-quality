# INTG-089 — DQX Surface, Version & Pinning

**Status:** Accepted — Phase 009 Group 04

DQX is an optional Databricks Labs quality-checking source family whose exact release/configuration is material to rule/result semantics.

The evaluated public release line is evolving and production use should pin/test a version. DQX availability does not make every DQX feature or generated rule applicable, authoritative, or stable across upgrades.
