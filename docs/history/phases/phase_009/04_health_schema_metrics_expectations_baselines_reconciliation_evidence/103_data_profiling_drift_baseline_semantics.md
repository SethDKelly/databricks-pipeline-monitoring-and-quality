# INTG-103 — Data-Profiling Drift & Baseline Semantics

**Status:** Accepted — Phase 009 Group 04

Data profiling can compare consecutive windows and optionally compare primary-table distributions with an explicitly configured baseline table, storing drift metrics in Delta tables.

A configured baseline table is a source reference set, not automatically an accepted framework Baseline or normative quality standard. HLTH-019–029 still govern regime, membership, comparability, representativeness and versioning.
