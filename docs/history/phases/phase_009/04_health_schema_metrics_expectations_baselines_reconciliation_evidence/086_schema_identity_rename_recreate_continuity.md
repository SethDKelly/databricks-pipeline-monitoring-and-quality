# INTG-086 — Schema Identity, Rename & Recreate Continuity

**Status:** Accepted — Phase 009 Group 04

Column/table names, ordinals and current metadata can describe structure but do not by themselves prove field identity across rename, drop/recreate, replacement or clone operations.

Historical continuity requires accepted Entity Identity/Change evidence. Same name is not same meaning; changed name is not automatically a new semantic field.
