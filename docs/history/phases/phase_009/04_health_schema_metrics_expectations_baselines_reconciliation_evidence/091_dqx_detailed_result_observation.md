# INTG-091 — DQX Detailed Result Observation

**Status:** Accepted — Phase 009 Group 04

DQX can emit detailed row-level warning/error result structures that identify failed check name/function/columns/filter and related issue detail.

Those outputs are evidence/Observation of that DQX execution. Warning/error columns are not universal severity, business Impact, composite health, or proof that every row/population was evaluated unless execution coverage establishes it.
