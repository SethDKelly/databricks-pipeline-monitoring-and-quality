# INTG-110 — Measurement ↔ Run / Output-Version Binding

**Status:** Accepted — Phase 009 Group 04

Where health analysis asks about a specific execution/output version, the measurement must be associated with that exact run/output or with a bounded state interval that makes the association valid.

Group 03 provenance gaps remain binding. Querying current/latest table state after a run does not prove the metric/schema result describes the output version that run produced.
