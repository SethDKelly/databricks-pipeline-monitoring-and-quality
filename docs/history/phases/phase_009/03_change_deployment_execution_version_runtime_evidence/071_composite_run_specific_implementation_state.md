# INTG-071 — Composite Run-Specific Implementation-State Binding

**Status:** Accepted — Phase 009 Group 03

A run-specific implementation state can include code/build revision, notebook/workspace content, job/task definition, parameters/configuration, libraries/runtime, schema/interface and target/environment facets.

One commit SHA or active job record does not universally bind the whole composite. Each material facet requires run-specific or time-valid evidence appropriate to its semantics.
