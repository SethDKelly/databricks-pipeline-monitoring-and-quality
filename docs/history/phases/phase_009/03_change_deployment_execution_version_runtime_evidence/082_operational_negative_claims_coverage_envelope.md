# INTG-082 — Operational Negative Claims & Coverage Envelope

**Status:** Accepted — Phase 009 Group 03

`No deployment`, `no activation`, `no run`, `no retry`, `no output`, `no consumption` and similar conclusions require proposition-specific opportunity/population/window coverage across the required source surfaces plus evidence that collection/querying was healthy.

Retention expiry, deleted GitHub workflow history, API pagination gaps, regional system-table limits, permission failures or absent input instrumentation constrain the negative; they never become evidence of absence.
