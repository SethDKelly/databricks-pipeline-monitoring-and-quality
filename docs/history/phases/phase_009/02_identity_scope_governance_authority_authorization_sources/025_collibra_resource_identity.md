# INTG-025 — Collibra Resource Identity

**Status:** Accepted — Phase 009 Group 02

Collibra resource UUIDs provide durable Collibra-local identity for assets, domains, communities and operating-model resources. Resource identity is separate from display name.

A Collibra UUID does not prove identity with a Unity Catalog object or repository artifact. Cross-system equivalence requires an explicit mapped identifier/relation/attribute contract with provenance.
