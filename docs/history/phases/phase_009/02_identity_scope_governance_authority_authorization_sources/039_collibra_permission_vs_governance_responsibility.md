# INTG-039 — Collibra Permission vs Governance Responsibility

**Status:** Accepted — Phase 009 Group 02

Collibra global/resource permissions authorize actions inside Collibra; Responsibilities assign resource roles and may inherit through communities/domains.

Permission to view/edit a Collibra asset does not grant access to the underlying data platform and a responsibility does not itself grant framework operational capability. AUTH responsibility and authorization concepts remain separate.
