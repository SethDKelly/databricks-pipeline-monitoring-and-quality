# INTG-048 — Optional-Source Absence & Degraded Governance

**Status:** Accepted — Phase 009 Group 02

Collibra and Immuta remain optional integrations. Their absence must degrade only the propositions they uniquely or materially support.

Missing optional governance data remains unknown/unsupported/partially supported as applicable; it cannot become `unowned`, `unclassified`, `unrestricted`, `not monitored` or `authorized`. Core framework semantics must remain valid with an explicit source gap.
