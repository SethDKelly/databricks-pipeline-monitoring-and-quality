# INTG-047 — Authority Conflict, Co-Authority & Fallback Across Sources

**Status:** Accepted — Phase 009 Group 02

When Unity Catalog, Collibra, Immuta, repository configuration or IAM assertions disagree, the framework applies AUTH-001–AUTH-008 to the exact proposition/facet/context/time.

Source count, product prominence, newest timestamp or fallback availability cannot choose a winner. Fallback is valid only when an explicit authority rule defines it and the activation condition is evidenced.
