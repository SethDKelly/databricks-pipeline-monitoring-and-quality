# INTG-035 — Assertion Authority Registry Requirement

**Status:** Accepted — Phase 009 Group 02

No evaluated platform feature automatically supplies the framework's full Assertion Authority rule set.

Unity Catalog ownership, Collibra Responsibilities, GitHub CODEOWNERS and Immuta roles/permissions are narrower facts. AUTH-001–AUTH-008 still require explicit proposition/category/facet/context/time authority rules. A governed repository or governance-system registry is a candidate realization, not selected architecture.
