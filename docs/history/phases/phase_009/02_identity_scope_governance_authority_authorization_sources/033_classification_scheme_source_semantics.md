# INTG-033 — Classification-Scheme Source Semantics

**Status:** Accepted — Phase 009 Group 02

Classification support is scheme/context specific. Unity Catalog governed tags and Collibra Data Classes can represent controlled classifications when an accepted authority rule designates their scheme and assignment process.

Ordinary Collibra tags are explicitly flexible/not strictly governed; Immuta tags are policy-targeting metadata. Neither is Classification truth by product label alone.
