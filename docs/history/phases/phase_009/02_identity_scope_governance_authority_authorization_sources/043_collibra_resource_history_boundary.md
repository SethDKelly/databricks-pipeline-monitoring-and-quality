# INTG-043 — Collibra Resource-History Boundary

**Status:** Accepted — Phase 009 Group 02

Collibra resource history can preserve many asset/domain/community changes and actor information, making it useful for semantic/responsibility/classification history when those fields are modeled there.

History completeness is configurable: Collibra 2026.08 documents that history logging can be disabled for selected attribute assignments. Historical absence therefore requires field-specific history-enabled coverage, not merely an empty history result.
