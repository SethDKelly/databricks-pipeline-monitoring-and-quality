# INTG-034 — Policy Context Source Semantics

**Status:** Accepted — Phase 009 Group 02

Policy text/reference, subject/context applicability, access-control configuration and effective enforcement are distinct source propositions.

Collibra may govern policy documentation/context; Unity Catalog privileges/ABAC express Databricks access-control policy; Immuta subscription/data policies express Immuta-governed access rules. None automatically proves legal interpretation, compliance or enforcement outside its supported plane.
