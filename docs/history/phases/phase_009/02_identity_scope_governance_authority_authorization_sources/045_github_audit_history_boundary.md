# INTG-045 — GitHub Audit-History Boundary

**Status:** Accepted — Phase 009 Group 02

GitHub organization/enterprise audit logs can provide actor/time history for repository governance events including permission and custom-property changes where the relevant plan/scope exposes them.

GitHub Enterprise Cloud documents 180-day general audit retention and seven-day Git-event retention. Repository governance replay beyond those horizons requires separately retained/streamed evidence where material.
