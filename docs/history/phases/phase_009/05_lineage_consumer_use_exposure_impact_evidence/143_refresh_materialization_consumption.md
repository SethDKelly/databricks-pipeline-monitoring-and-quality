# INTG-143 — Refresh / Materialization Consumption Evidence

**Status:** Accepted — Phase 009 Group 05

A dashboard/materialized-view/streaming-table/report refresh is an encounter mode distinct from human view. Exact refresh execution plus source read/version evidence can establish refreshed-state consumption.

Refresh success alone does not prove which state/version was used, nor that a human subsequently viewed the refreshed result.
