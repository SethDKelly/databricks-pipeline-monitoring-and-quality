# INTG-013 — Coverage, Completeness & Observable Population Boundary

Every material capability identifies what population, path set, event class, workspace/account, time window, consumer mode or control surface is observable.

Coverage can be complete for a bounded proposition, partial, sampled, filtered, delayed, unknown, or explicitly outside scope.

A complete result for one path/cohort/source mode cannot be generalized to all paths/consumers/modes.

Coverage metadata is evidence for the scope of a conclusion, not a universal integration completeness percentage.
