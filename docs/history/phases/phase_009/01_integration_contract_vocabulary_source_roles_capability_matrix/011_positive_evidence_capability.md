# INTG-011 — Positive Evidence Capability

A source capability records which positive propositions it can directly evidence and under what conditions.

Examples include a run occurred, a deployment attempt was recorded, a schema field existed, a metric value was observed, a relationship was asserted, a consumer query occurred, or a Gate decision was issued.

Positive-event support does not imply lifecycle completion, downstream consequence, causality, completeness of the event population or ability to prove the corresponding negative.

The exact positive proposition and required identity/time/grain bindings remain explicit.
