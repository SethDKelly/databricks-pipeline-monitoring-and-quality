# INTG-018 — Conflict, Fallback & Source-Precedence Boundary

When sources disagree, the capability matrix preserves the conflicting assertions/evidence and their identities, times, scopes and roles.

Fallback accessibility is not precedence. A secondary source does not become authoritative because the preferred source is unavailable.

Any resolution rule must come from accepted proposition/category/context/time-specific authority or evidence rules and be referenced explicitly.

Absent such a rule, conflict remains conflict; recency, specificity, source count or synchronization order cannot select a winner by convenience.
