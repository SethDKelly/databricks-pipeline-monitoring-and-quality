# INTG-019 — Support Classification & Residual Gap Taxonomy

Integration support is classified for a **bounded proposition + source set + context**, never for a vendor as a whole.

Allowed planning outcomes are:

- `supported` — evaluated source capability can satisfy the required contract under stated conditions;
- `partially supported` — useful evidence exists but one or more required identity/time/coverage/authority/retention/disclosure dimensions remain gapped;
- `unsupported` — evaluated source capability cannot satisfy a required dimension;
- `unknown / not yet verified` — capability or limitation has not been established sufficiently;
- `not applicable` — the source/requirement does not apply to the bounded proposition/context.

These are integration-feasibility results, not proposition truth or confidence states.
