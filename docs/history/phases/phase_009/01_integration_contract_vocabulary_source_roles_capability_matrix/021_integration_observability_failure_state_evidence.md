# INTG-021 — Integration Observability & Failure-State Evidence

A source contract records what evidence can distinguish source-side absence from integration failure modes such as authentication failure, permission denial, throttling, timeout, partial pagination, schema/API drift, parser failure, delayed indexing or source outage.

Integration-health evidence is separate from the monitored product proposition.

If the framework cannot determine whether retrieval was complete, strong negative conclusions that depend on that retrieval are not supported for the affected interval.

This contract describes required observability semantics without choosing monitoring infrastructure.
