# INTG-003 — Evidence Role Taxonomy & Source Assertion Type

A source surface can have one or more proposition-specific evidence roles, including:

- observational/measured evidence;
- declared/assertive metadata;
- normative/reference assertion;
- operational event/action record;
- relationship/association evidence;
- authorization/permission decision evidence;
- contextual/limiting evidence;
- derived/projection/reporting evidence.

The role describes how source output participates in reasoning. It does not establish Assertion Authority, evidentiary sufficiency, independence or disclosure permission.

A derived/reporting surface must preserve its upstream derivation where known so it is not counted as independent corroboration.
