# HLTH-065 — Late Evidence, Progressive Summary Revision & Non-Rewriting History

**Status:** Accepted — Phase 006 Group 06

## Purpose

Define how broader health summaries evolve as later evidence arrives without mutating earlier narrow results or retained historical composites.

## Rules

- A fast operational result can remain historically valid for its narrow proposition even when later enriched evidence changes the broader health summary.
- A composite summary should expose whether required components are pending when it is not yet complete for the intended profile/use.
- Later DQ/reconciliation/distribution evidence can move a broader composite from indeterminate to healthy/degraded, or can challenge an earlier broader summary when corrected/late evidence warrants reassessment.
- Corrected evidence creates a new Assessment/reassessment with supersession provenance rather than silent mutation.
- An earlier `healthy` composite is retained as an actual historical result only if it was legitimately resolved under the then-applicable profile and evidence; a later result can show that subsequent evidence changed retrospective understanding.
- If an earlier display was only a narrow operational summary, later broad degradation must not be framed as though the earlier operational fact was false.
- Pending evidence, late evidence, correction, and newly expanded profile scope remain distinct reasons for a summary change.
- Historical communication remains separate from current retrospective recomputation.

## Invariant

Progressive maturation revises the proposition whose evidence changed; it does not rewrite unrelated earlier truths.
