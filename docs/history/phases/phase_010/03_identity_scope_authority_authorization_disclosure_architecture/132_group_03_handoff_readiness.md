# ARCH-132 — Group 03 Handoff Readiness

**Status:** Accepted

Group 04 may begin only with durable canonical entity/principal identity, Monitoring Scope, Assertion Authority, Capability Authorization and disclosure primitives available as explicit architecture contracts.

Connector code must consume these primitives rather than invent identity, scope or permission semantics per source.

Group 03 selects no source-adapter, synchronization, event-bus, auth-provider or policy-engine product.
