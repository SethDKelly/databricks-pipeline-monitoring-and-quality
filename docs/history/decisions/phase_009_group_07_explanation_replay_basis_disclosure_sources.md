# Phase 009 Group 07 Decisions — Explanation, Replay, Basis & Disclosure Sources

### D-1173 — Explanation source support is evaluated against the completed Phase 008 contract
**Status:** Accepted
Group 07 maps source feasibility and does not redefine Explanation semantics.

### D-1174 — Material statements require internal source-basis identity
**Status:** Accepted
Rendered wording/citation text is not sufficient provenance by itself.

### D-1175 — Basis references preserve exact source-surface identity and relevant revision context
**Status:** Accepted
Vendor/product names are too coarse for historical inspection.

### D-1176 — Supporting, contradicting and limiting basis roles remain statement-relative
**Status:** Accepted
Source identity does not define one global evidence role.

### D-1177 — Basis/source count does not create confidence
**Status:** Accepted
Common-derived evidence remains common-derived.

### D-1178 — Historical Explanation binds event/effective time and knowledge cut independently
**Status:** Accepted
Communication time and source availability time remain additional coordinates when material.

### D-1179 — Event timestamp does not establish availability by knowledge cut
**Status:** Accepted
As-known inclusion requires evidence the basis was actually available by `K`.

### D-1180 — Retrieval today cannot backfill historical knowledge
**Status:** Accepted
Old source event time is insufficient.

### D-1181 — Late evidence may change current retrospective Explanation without rewriting earlier as-known state
**Status:** Accepted
Historical uncertainty can remain historically valid.

### D-1182 — Source corrections/supersessions preserve predecessor state and availability timing where retained
**Status:** Accepted
Current preferred source state does not erase history.

### D-1183 — Current-state-only sources cannot manufacture historical state
**Status:** Accepted
Latest value is not a historical ledger.

### D-1184 — Retention expiry/deletion/truncation/encryption become explicit replay limitations
**Status:** Accepted
Missing detail is not reconstructed by narrative convenience.

### D-1185 — Reconstructed historical Explanation is not actual retained communication
**Status:** Accepted
This distinction is mandatory even when reconstructed wording appears identical.

### D-1186 — Actual retained communication requires authentic content/context evidence
**Status:** Accepted
Source telemetry alone does not prove what was communicated.

### D-1187 — Communication identity includes time, audience/destination and relevant delivery context
**Status:** Accepted
Content without context is incomplete communication history.

### D-1188 — Delivery evidence does not establish exact rendered content
**Status:** Accepted
Delivery also does not establish reading, comprehension or reliance.

### D-1189 — Missing retained communication remains missing
**Status:** Accepted
A separately labeled reconstruction is allowed only when source history supports it.

### D-1190 — Mutable discussion/ticket/comment records are retained communication only within their surviving revision history
**Status:** Accepted
Current body is not arbitrary historical body.

### D-1191 — Statement identity can survive wording/detail/basis changes when proposition-defining scope is stable
**Status:** Accepted
Changed subject/scope/event target/knowledge perspective creates a new identity or comparison.

### D-1192 — New basis can enrich without strengthening source status
**Status:** Accepted
Explanation delta classes remain explicit.

### D-1193 — Partial answerability is valid under source-history or authorization gaps
**Status:** Accepted
No universal Explanation completeness percentage is introduced.

### D-1194 — Source outage/lag/permission failure is a basis limitation, not proposition-level negative truth
**Status:** Accepted
Narrative completion cannot hide source degradation.

### D-1195 — Internal basis inspectability is required even when visible basis is restricted
**Status:** Accepted
Internal traceability and external disclosure are separate.

### D-1196 — Visible citation/reference does not grant source retrieval or disclosure permission
**Status:** Accepted
Reference, accessibility and authorization remain separate.

### D-1197 — Current requester authorization governs current disclosure of historical basis
**Status:** Accepted
Historical actor access does not transfer to the current requester.

### D-1198 — Historical actor authorization and current requester disclosure are non-rewriting
**Status:** Accepted
Current revocation does not erase authentic prior communication.

### D-1199 — Result/context/limitation/basis/provenance/detail may require separate visibility decisions
**Status:** Accepted
Visible conclusion does not imply visible raw basis.

### D-1200 — Safe basis abstraction is epistemically monotone
**Status:** Accepted
Redaction/generalization cannot strengthen, reverse or broaden the statement.

### D-1201 — Basis existence/count/type/provenance can itself be sensitive
**Status:** Accepted
Opaque metadata is disclosure-governed.

### D-1202 — Query text/parameters/errors are independently sensitive basis facets
**Status:** Accepted
Administrative source access does not imply Explanation-display authority.

### D-1203 — Actor/reviewer/consumer identity is independently disclosure-governed
**Status:** Accepted
Redaction cannot merge materially distinct subjects.

### D-1204 — Observer-relative source views cannot support absence by non-return
**Status:** Accepted
Permission/region/workspace filtering remains attached.

### D-1205 — Databricks system-table history has per-surface retention semantics
**Status:** Accepted
No generic indefinite `system` ledger is assumed.

### D-1206 — Databricks query-history content is conditionally inspectable
**Status:** Accepted
CMK blanking and truncation are first-class basis limitations.

### D-1207 — Databricks alert history can prove definition/evaluation/delivery propositions within its scope
**Status:** Accepted
It does not prove exact Explanation content or human reliance.

### D-1208 — GitHub audit history is retention-bound and externally retainable
**Status:** Accepted
Externally streamed duplicates remain common-derived.

### D-1209 — GitHub comment edit history is useful but not immutable
**Status:** Accepted
Revision deletion and edit caps constrain exact historical communication.

### D-1210 — Collibra history is facet/configuration specific
**Status:** Accepted
History-disabled attributes and inherited-responsibility gaps remain explicit.

### D-1211 — Collibra visibility is observer-relative
**Status:** Accepted
Hidden resource/history is not absent resource/history.

### D-1212 — Immuta audit is strong within integration scope but short-lived by default in SaaS
**Status:** Accepted
Long-horizon inspection requires verified export/retention.

### D-1213 — Current source access does not prove exact prior `inspectBasis` presentation
**Status:** Accepted
Prior visible projection requires retained communication/projection evidence.

### D-1214 — Comparative Explanation evaluates each side's source coverage independently
**Status:** Accepted

### D-1215 — More visible/more detailed source basis does not mean more true
**Status:** Accepted
Authorization/detail changes remain distinct from source status.
