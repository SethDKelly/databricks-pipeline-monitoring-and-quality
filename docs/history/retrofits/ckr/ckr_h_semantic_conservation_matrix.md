# CKR-H Semantic Conservation Matrix — Integration, Source Authority & Evidence Availability

**Status:** CANDIDATE REVIEW

**Purpose:** prove that migrating INTG-001–INTG-270 from Phase 009 into bounded canonical integration contracts changes documentation ownership/routing only and does not strengthen, weaken or collapse accepted DMTZ semantics.

## Core source-capability boundaries

| Boundary | Conserved rule |
|---|---|
| Source availability / authority | **available ≠ relevant ≠ eligible ≠ authoritative ≠ sufficient ≠ authorized**. Retrieval convenience, recency, product prominence or source count creates no authority. |
| Identity | **source-local identifier/name ≠ ecosystem Entity Identity**. Cross-system identity requires explicit governed mapping evidence. |
| Association | **timestamp proximity ≠ exact cross-system association**. Deployment↔run, run↔version, consumer↔state and control decision↔enforcement joins require explicit evidence. |
| Positive / negative capability | **positive-event support ≠ negative-evidence capability**. Strong negatives require bounded opportunity/population/path/window, sufficient coverage and source health. |
| Empty results | **no returned record ≠ absence** when pagination, retention, permission, lag, throttling, outage, optional-source state or collection completeness is unresolved. |
| Coverage | One observed mode/path/population ≠ global completeness. Aggregate/asset evidence cannot silently answer narrower field/run/version/consumer/path propositions. |
| Historical replay | **current-state availability ≠ historical replay capability**. Current state cannot be projected backward without qualifying retained history. |
| Knowledge cuts | **late/backfilled evidence now ≠ evidence available at an earlier knowledge cut**. Later evidence may alter current retrospective interpretation only. |
| Independence | **multiple endpoints ≠ independent corroboration when commonly derived**. Replicas/exports/duplicates retain common derivation. |
| Conflict/fallback | **fallback availability ≠ inherited authority**. Source conflict remains conflict absent accepted evidence/authority resolution. |
| Integration health | **integration failure ≠ monitored-product negative**. Auth failure, denial, throttling, lag, partial pagination, schema/API drift, parser failure, retention expiry and outage are evidence limitations. |
| Feasibility | **support classification ≠ truth/confidence/completeness**. Supported/partial/unsupported/unknown/not-applicable describe integration feasibility only. |
| Latency | **latency ≠ event/effective truth**. Latency controls when evidence may enter knowledge cut K. |
| Cost/quota | **quota/cost ≠ evidence authority**. Operational limits may constrain feasible coverage/latency but do not change proposition semantics. |

## Governance / runtime boundaries

- Unity Catalog/Collibra/Immuta/GitHub source-local identities do not become ecosystem Entity Identity without explicit crosswalks.
- Monitoring Scope and Assertion Authority are not automatically supplied by vendor ownership/role metadata.
- Current governance/permission state ≠ historical governance/enforcement state.
- Optional governance/control integration absence is an explicit gap, not a benign/default result.
- Git commit SHA ≠ governed Change Intent without an accepted governance rule.
- **GitHub Actions success ≠ Databricks activation**.
- GitHub Deployment status ≠ target activation.
- Direct-Git `used_commit` support does not fabricate bundle/workspace-source run commit provenance.
- One code commit ≠ complete composite implementation state.
- **configured dependency ≠ actual precedence ≠ waiting ≠ version consumption**.
- Retry ≠ repair ≠ restart ≠ rerun ≠ backfill.
- Generic exact multi-input consumed-version manifests remain unsupported/conditional where no instrumentation exists.
- **execution success ≠ output existence ≠ freshness/currentness ≠ health**.

## Health / Impact / control boundaries

- Realized schema ≠ governed semantic definition ≠ consumer contract ≠ compatibility Assessment.
- Declared constraint ≠ empirically measured integrity.
- DQ rule/profile candidate ≠ governed Expectation.
- Metric/profile/anomaly result ≠ universal health truth.
- **profile metric ≠ Baseline membership ≠ drift Assessment ≠ normative health**.
- Commit freshness ≠ event freshness.
- **captured lineage event ≠ encounter ≠ exposure**.
- Dashboard access ≠ dataset execution ≠ query-result receipt.
- Platform query/read ≠ external report view/business reliance.
- Exact object encounter ≠ exact affected-version exposure when version binding is absent.
- Multi-hop exposure is non-transitive.
- **exposure ≠ effect ≠ consequence ≠ causal attribution**.
- View/delivery ≠ comprehension ≠ decision reliance ≠ changed action ≠ consequence.
- **localization ≠ Causal Claim**; causal `confirmed` remains REF-017 + AUTH-034 gated.
- Control request/configuration/acceptance ≠ opportunity-specific enforcement.
- **Safeguard enforcement ≠ prevented exposure**; REF-028 retains encounter-opportunity/path/coverage burdens.
- No encounter opportunity ≠ prevention credit.
- Databricks cancellation ≠ pre-start Gate HOLD.
- Gate decision/delivery/acceptance ≠ enforcement.
- **HOLD/ADMIT ≠ execution outcome**.
- Missing control telemetry ≠ fail-open/fail-closed.

## Explanation / historical boundaries

- Source history ≠ evidence availability by knowledge cut.
- Source replay ≠ authentic retained communication.
- Delivery evidence ≠ exact communication content.
- Current requester disclosure authorization ≠ historical actor authorization.
- Visible source reference/citation ≠ permission to inspect source basis.
- Basis/source count ≠ confidence.
- Safe redaction/abstraction can reduce visible detail but cannot strengthen internal truth.
- **historical source state ≠ as-known-at-cut Explanation ≠ retained actual communication ≠ current retrospective Explanation**.
- Missing retained communication remains missing; reconstruction never becomes authentic prior communication.

## Consolidated anti-score rule

There is **no universal source-support/confidence/completeness/health/Impact/control/replay score**. Integration capability remains proposition + source-set + context bound.
