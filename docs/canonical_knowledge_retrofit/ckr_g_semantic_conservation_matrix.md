# CKR-G Semantic Conservation Matrix — Questioning, Explanation & Experience

**Status:** CANDIDATE REVIEW

CKR-G is an authority migration of accepted Phase 008 semantics. It is not an A4 semantic redesign.

| Boundary | Required conserved meaning |
|---|---|
| question | question ≠ truth ≠ authorization; wording ≠ proposition identity |
| composition | answer statement ≠ independent truth; direct projection ≠ derived cross-concept statement |
| basis | basis count ≠ confidence; common-derived basis ≠ independent corroboration |
| sibling safety | one supported sibling does not strengthen an unresolved sibling |
| operational shorthand | ran ≠ succeeded ≠ produced output ≠ current/fresh output ≠ healthy |
| health/schema | structural compatibility ≠ statistical comparability ≠ normative quality; Baseline typicality ≠ Expectation outcome |
| change/runtime | Change Intent ≠ Deployment ≠ activation ≠ realized Change; dependency ≠ precedence ≠ waiting ≠ consumption |
| causality | Investigation/localization ≠ Causal Claim; supported ≠ confirmed; `confirmed` remains REF-017 + AUTH-034 gated |
| Impact | candidate/reachable ≠ opportunity ≠ exposure ≠ effect ≠ consequence ≠ causal attribution |
| controls | Safeguard administration ≠ enforcement ≠ prevented exposure ≠ recovery; readiness ≠ Gate decision ≠ enforcement ≠ execution; Gate ≠ Safeguard |
| governance | Responsibility Assignment ≠ fault/cause/authority/permission; Assertion Authority ≠ factual truth/evidence sufficiency/Capability Authorization |
| uncertainty | unknown/unresolved ≠ false/absent/safe; unavailable ≠ negative evidence; restricted/redacted ≠ absent |
| negative claims | absence of evidence ≠ evidence of absence; question polarity never lowers negative-evidence burden |
| disclosure | safe abstraction can reduce detail but cannot strengthen truth; opaque existence is independently governed |
| mixed visibility | hidden/restricted basis remains internally traceable and material hidden limitations still constrain visible conclusions |
| progression | elapsed time/rewording ≠ evidence or maturity; basis enrichment ≠ automatic status strengthening |
| retention | retained actual communication ≠ timeless truth; reconstructed historical Explanation ≠ actual prior communication |
| historical views | historical source state ≠ as-known-at-cut Explanation ≠ retained actual communication ≠ current retrospective Explanation |
| temporal coordinates | event/effective time ≠ knowledge cut ≠ communication time |
| scoring | no universal Explanation confidence, completeness, maturity, RCA, Impact, control-effectiveness, answer-quality or replay score |
| truth model | no separate business/executive/audience truth model; all views are authorized projections over accepted truth |
| scope | EXPL-001–EXPL-160 exactly; no EXPL-161, new concept, new stable family or architecture choice |

## Cross-CKR constraints

- concepts/SYN/REF/AUTH/HLTH/OPS remain canonical and are consumed, not reopened;
- INTG and ARCH remain legacy-authoritative until CKR-H/I;
- Explanation may compose accepted derived propositions but cannot manufacture stronger source-domain state;
- current authorization controls disclosure and does not alter source truth or historical communication;
- Implementation 001-A remains blocked until CKR-K.
