# Authority

Current DMTZ authority documentation covers assertion standing, authorization, governance, confirmation, disclosure, and high-consequence use without collapsing those responsibilities into one generic permission model.

- [`vocabulary.md`](vocabulary.md) defines the shared current authority vocabulary.
- AUTH-001–AUTH-053 are owned by the current authority resources in this directory.
- Related evidence, control, and explanation constraints remain independently owned by their current contract and experience resources.

Use [`../canonical_knowledge_retrofit/canonical_ownership_inventory.json`](../canonical_knowledge_retrofit/canonical_ownership_inventory.json) for exact ownership and stable-ID routing. Historical governance and authority design material is preserved under [`../history/`](../history/README.md).
