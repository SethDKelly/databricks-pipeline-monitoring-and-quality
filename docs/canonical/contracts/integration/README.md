## Non-collapse rule

Integration capability never becomes source-domain truth by convenience. In particular:

**available ≠ relevant ≠ eligible ≠ authoritative ≠ sufficient ≠ authorized**;
**source-local identity ≠ ecosystem Entity Identity**;
**timestamp proximity ≠ exact join**;
**positive support ≠ negative coverage**;
**source history ≠ availability-by-K ≠ retained communication**;
**lineage ≠ encounter ≠ exposure ≠ effect ≠ consequence ≠ cause**;
**configuration/decision ≠ enforcement ≠ prevention/recovery**;
**support class/cost/latency ≠ confidence/truth**.

ARCH-001–ARCH-500 remains independently legacy-authoritative under Phase 010/CKR-I until that later cutover.
