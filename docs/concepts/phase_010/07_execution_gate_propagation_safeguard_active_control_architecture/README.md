## Boundary

Gate and Safeguard remain distinct active-control concepts. Configuration/request/authorization does not prove enforcement; enforcement does not automatically prove prevented exposure; ADMIT/HOLD do not prove execution/non-execution by themselves.

A model-generated recommendation, Investigation lead, Explanation sentence, semantic-search result or reasoning cache entry cannot itself become a Gate/Safeguard decision. Active control must consume exact governed criterion/proposition/Assessment identities through deterministic control logic and explicit authorization.
