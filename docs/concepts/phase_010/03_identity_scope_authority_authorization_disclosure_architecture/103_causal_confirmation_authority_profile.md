# ARCH-103 — Causal Confirmation Authority Profile

**Status:** Accepted

Causal confirmation uses an explicit authority profile over claim class, subject scope, reviewer/automation eligibility, separation-of-duty conditions and applicable time.

The resolver can establish authorization/authority eligibility only; confirmation still requires REF-017 evidence sufficiency and AUTH-034.

No model, vendor RCA label or seniority shortcut can bypass that joint gate.
