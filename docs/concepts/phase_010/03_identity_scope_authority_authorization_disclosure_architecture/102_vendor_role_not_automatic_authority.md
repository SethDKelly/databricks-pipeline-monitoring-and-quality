# ARCH-102 — Vendor Role Is Not Automatic Assertion Authority

**Status:** Accepted

Unity Catalog ownership, GitHub repository ownership/review role, Collibra responsibility or Immuta permission may be source evidence for organization rules but is not automatically DMTZ Assertion Authority.

Mappings from vendor roles to authority are explicit, revisioned and proposition-specific.

Role absence likewise does not prove absence of authority unless the governing rule says so.
