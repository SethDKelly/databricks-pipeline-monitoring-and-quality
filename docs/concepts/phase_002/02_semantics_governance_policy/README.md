# Group 02 — Semantics, Governance & Policy

**Status:** Candidate review group

## Goal

Define what an identified entity **means**, **who is responsible for it**, **how it is classified**, and **what policy context applies** without collapsing these different concerns.

## Concepts

- [Semantic Definition](semantic_definition.md)
- [Ownership](ownership.md)
- [Classification](classification.md)
- [Policy Context](policy_context.md)

## Key design distinction

A PHI classification can inform policy context, but neither the classification nor the policy context grants authorization or proves compliance. Likewise, ownership does not make an owner authoritative for every semantic or policy statement.

## Group exit gate

Advance when the product can explain meaning, responsibility, sensitivity, and applicable handling context as separate provenance-bearing facts.
