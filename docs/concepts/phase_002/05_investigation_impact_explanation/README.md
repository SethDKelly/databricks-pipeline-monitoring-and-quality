# Group 05 — Investigation, Impact & Explanation

**Status:** Candidate review group

## Goal

Define how the product organizes an inquiry, represents causal reasoning, determines downstream exposure, preserves human context, and communicates evidence-grounded answers.

## Concepts

- [Investigation](investigation.md)
- [Causal Claim](causal_claim.md)
- [Impact](impact.md)
- [Annotation](annotation.md)
- [Explanation](explanation.md)

## Critical distinction

Investigation organizes inquiry; Causal Claim represents an explanation under evaluation; Impact represents downstream exposure; Annotation adds human context; Explanation communicates a role-appropriate synthesis. None is allowed to rewrite source observations.

## Group exit gate

Phase 002 can exit when the canonical RCA scenario can be expressed with explicit evidence, uncertainty, competing causes, downstream impact, and business-facing explanation while preserving security boundaries.
