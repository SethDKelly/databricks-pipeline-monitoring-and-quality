# INTG-051 — Repository Revision & Change-Record Identity

**Status:** Accepted — Phase 009 Group 03

Git commit SHA is the stable repository-revision identity for source content. Branch/tag names, pull-request numbers, merge state, commit messages and review metadata are related source facts, not substitutes for the exact revision.

A pull request, issue, release or commit may inform **Change Intent** only when an accepted governance rule defines which record/facet carries that proposition. Repository existence alone does not create Change Intent.
