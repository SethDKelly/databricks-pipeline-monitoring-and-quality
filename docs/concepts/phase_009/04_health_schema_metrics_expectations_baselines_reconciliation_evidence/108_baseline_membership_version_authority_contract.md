# INTG-108 — Baseline Membership, Version & Authority Contract

**Status:** Accepted — Phase 009 Group 04

A framework Baseline requires explicit reference-set membership, subject/metric/regime/window/context and version semantics even when source products expose historical profiles, learned models or configured baseline tables.

Vendor historical data is candidate reference evidence. Recency, sample size or platform-generated baseline status cannot create membership/authority by convenience.
