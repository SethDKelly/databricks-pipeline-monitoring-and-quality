# INTG-090 — DQX Rule Identity, Definition & Storage

**Status:** Accepted — Phase 009 Group 04

DQX rule/check metadata can carry name, function/expression, arguments, columns, filter and criticality and can be stored in files/tables/configuration.

A DQX check becomes a governed framework Expectation only when an accepted authority/version/applicability rule binds that exact definition. Storage location or check availability does not create normative standing.
