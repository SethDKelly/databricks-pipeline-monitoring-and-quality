# INTG-094 — DQX Criticality / Action Governance Boundary

**Status:** Accepted — Phase 009 Group 04

DQX criticality and optional actions/alerting/fail-pipeline behavior describe DQX rule handling and reaction semantics.

They do not automatically equal framework severity, priority, waiver, high-consequence-use eligibility, Execution Gate decision, or Capability Authorization. Those mappings require explicit governance/control contracts.
