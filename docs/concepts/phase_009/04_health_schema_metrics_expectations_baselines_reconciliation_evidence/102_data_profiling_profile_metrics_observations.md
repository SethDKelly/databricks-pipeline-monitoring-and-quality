# INTG-102 — Data-Profiling Profile Metrics as Observations

**Status:** Accepted — Phase 009 Group 04

Databricks data profiling writes profile-metric Delta tables containing descriptive statistics by table/column, time window, slice/grouping context and applicable model context.

These outputs are descriptive Observations. Built-in metric availability does not create metric-profile selection, a normative Expectation, or a framework health result.
