# INTG-116 — Health-Source Historical Replay & Retention

**Status:** Accepted — Phase 009 Group 04

Historical health replay depends on retained rule/metric definitions, source data/version context, result records, Baseline/reference membership and relevant source histories.

Delta table history defaults, DQX configured storage, pipeline event logs, profiling metric Delta tables and anomaly-detection system history have different retention/configuration semantics. No source is an indefinite universal health ledger by default.
