# INTG-106 — Anomaly-Detection Health-Status Projection

**Status:** Accepted — Phase 009 Group 04

The data-quality-monitoring result surface exposes vendor statuses such as Healthy, Unhealthy, Training, Error and Unknown plus component freshness/completeness status.

The vendor table-level status remains a source-owned composite assertion. DMTZ may project or use its components, but cannot substitute that label for a governed HLTH-055 composite-health profile without explicit composition/authority semantics.
