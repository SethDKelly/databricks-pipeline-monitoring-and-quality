# INTG-111 — Reconciliation Source Evidence Contract

**Status:** Accepted — Phase 009 Group 04

DQX dataset checks, explicit SQL queries, Metric Views and other measurements can provide inputs to transformation reconciliation when they bind the exact transformation/version, inputs/output, grain, population, keys/measures and window required by HLTH-041–054.

A generic row-count/check result is not reconciliation merely because upstream and downstream assets are related.
