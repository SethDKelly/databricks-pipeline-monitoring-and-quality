# INTG-092 — DQX Summary Metrics & Run Binding

**Status:** Accepted — Phase 009 Group 04

DQX summary metrics can record input/error/warning/valid counts and custom quality metrics, and current DQX supports a run identifier for cross-referencing detailed and summary results.

Exact DQX execution/run identity, input snapshot/version, rule-set version and metric-table append semantics must be retained where the framework needs historical Assessment or exact-run attribution.
