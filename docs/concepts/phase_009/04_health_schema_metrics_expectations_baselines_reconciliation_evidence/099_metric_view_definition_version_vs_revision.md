# INTG-099 — Metric-View Specification Version vs Definition Revision

**Status:** Accepted — Phase 009 Group 04

Metric-view YAML `version` identifies the Databricks YAML specification, not an organization-assigned revision of the metric definition.

Framework metric-definition history therefore requires its own exact revision/provenance evidence for material semantic changes. Runtime/feature availability must also be recorded separately from business metric version identity.
