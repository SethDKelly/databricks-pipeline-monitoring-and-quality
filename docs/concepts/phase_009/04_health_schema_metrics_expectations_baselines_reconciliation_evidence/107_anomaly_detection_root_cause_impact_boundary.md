# INTG-107 — Anomaly-Detection Root-Cause / Impact Label Boundary

**Status:** Accepted — Phase 009 Group 04

Databricks anomaly-detection outputs can include upstream-job `root_cause_analysis` metadata and a downstream-impact summary derived from dependency/query information.

These fields are useful leads/context only. They do not become framework Causal Claim confirmation, consumer exposure, realized Impact, consequence, or universal severity without the Phase 004/007 evidence chain.
