# INTG-098 — Metric-View Definition & Measure Semantics

**Status:** Accepted — Phase 009 Group 04

Unity Catalog metric views can define versioned-YAML-format source, joins, filters, fields/dimensions, measures, window logic and optional materialization context.

They are strong candidates for governed reusable metric definitions when explicit semantic/Assertion Authority designates them. A metric view's existence does not by itself create framework metric-profile inclusion or normative health use.
