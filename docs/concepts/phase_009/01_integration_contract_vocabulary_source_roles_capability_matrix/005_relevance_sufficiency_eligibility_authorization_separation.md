# INTG-005 — Relevance, Sufficiency, Eligibility & Authorization Separation

A source can be relevant without being sufficient. An authoritative assertion can still lack the evidence needed for a different factual conclusion. Eligible evidence can still be stale or incomplete for a particular use.

Each capability therefore distinguishes:

- semantic relevance to the proposition;
- evidence eligibility/applicability;
- whether it can be sufficient alone under stated conditions, can only contribute, or cannot satisfy the conclusion;
- Assertion Authority where applicable;
- Capability Authorization/disclosure permission.

No field is inferred from another.
