# INTG-017 — Duplicate, Common Derivation & Independence

Multiple endpoints, tables, exports or vendor products can expose the same underlying record or derive from one common telemetry stream.

A capability matrix records known derivation/provenance relationships so duplicate/common-derived evidence is not counted as independent corroboration.

Independent corroboration requires materially independent evidence production for the proposition, not merely a different API or storage surface.

Unknown derivation remains a limitation; source count never becomes confidence arithmetic.
