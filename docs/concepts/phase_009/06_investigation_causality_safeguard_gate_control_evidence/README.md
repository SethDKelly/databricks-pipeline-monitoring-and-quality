## Goal

Map concrete evidence sources for Investigation/localization, Causal Claim evaluation and active-control history while preserving the accepted boundaries among inquiry, cause, control decisions, enforcement and effects.

## Group 05 entry contract

Group 06 may consume accepted Lineage events/effective relationships, query/read/result/dashboard/cache/application encounter evidence, bounded exposure results and downstream effect/consequence evidence **only where INTG-120–INTG-153 establish them**.

Material Group 05 limitations remain attached: Unity Catalog lineage is incomplete; rename/path identity can require reconciliation; generic lineage/query history does not universally identify the exact table version consumed; dashboard cache can serve prior state without a new query; external BI/application/business-use boundaries require their own telemetry; multi-hop exposure is non-transitive; and historical Impact reconstruction spans heterogeneous retention windows.

Topology, query timing, exposure, downstream effect, consequence, popularity/priority or vendor impact/root-cause labels do **not** establish causal status. A safe/non-exposed path also does not prove prevention by a Safeguard without the accepted REF-028 opportunity/control evidence.
