# Phase 009 Group 06 — Investigation, Causality, Safeguard, Gate & Control Evidence

**Status:** Not started

## Goal

Map concrete evidence sources for Investigation/localization, Causal Claim evaluation and active-control history while preserving the accepted boundaries among inquiry, cause, control decisions, enforcement and effects.

## Primary questions

- Which source evidence can support first-observed, earliest-evidenced, transformation-boundary and consumer-effect localization?
- What evidence can discriminate among Investigation leads rather than merely correlate with them?
- Which source assertions/reviews can support or confirm Causal Claims, and which Assertion Authority rules apply?
- How are human review/approval/Annotation records retained and joined to the exact causal proposition?
- Which sources establish Propagation Safeguard proposal, authorization, request, acceptance, effective enforcement, release and protected path/cohort?
- Which sources establish Execution Gate criterion, evidence suitability, readiness, decision, delivery/acceptance, override/fallback and effective enforcement?
- What telemetry can prove prevention or control effect versus merely show active configuration?
- How are overlapping controls and degraded/missing control telemetry represented without inferring precedence or fail-open/fail-closed behavior?
- What historical retention is required to replay the exact decision/enforcement knowledge cut?

## Boundary

Investigation/localization ≠ causality. Control configuration/request/decision ≠ enforcement. Broader prevention/delay/harm attribution remains Causal Claim work except the accepted bounded prevented-exposure determination.

## Handoff

Group 07 evaluates whether the accumulated source contracts can support authorized, traceable and historical Explanation/`inspectBasis` behavior.
