# INTG-192 — Databricks `Run if` / `If/else` Gate Mapping

**Status:** Accepted — Phase 009 Group 06

Lakeflow Jobs dependency conditions and `If/else` condition tasks expose concrete branch/control-flow results that can implement a bounded Execution Gate only under explicit criterion/opportunity mapping.

Native task condition semantics do not themselves create DMTZ readiness, authorization or universal Gate status.
