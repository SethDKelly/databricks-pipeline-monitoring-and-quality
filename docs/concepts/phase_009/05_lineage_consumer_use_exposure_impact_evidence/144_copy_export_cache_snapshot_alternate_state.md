# INTG-144 — Copy, Export, Cache & Snapshot Alternate-State Evidence

**Status:** Accepted — Phase 009 Group 05

Copied/exported/cached/snapshot state forms a distinct encounter path. A consumer can avoid suspect current state by using a safe prior copy while separately being stale, or can remain exposed through an affected copy after the source is corrected.

Source correction does not rewrite derived-copy encounter history.
