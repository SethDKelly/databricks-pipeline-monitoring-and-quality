# INTG-148 — Non-Exposure Negative Claim Coverage

**Status:** Accepted — Phase 009 Group 05

`Not exposed` requires bounded encounter opportunity plus sufficient path/population/version/source coverage and source health for the exact consumer proposition.

Missing lineage, expired query history, audit gaps, external-BI blind spots, unknown cache state or safe evidence on only one path must remain limitations rather than global non-exposure.
