# INTG-024 — Unity Catalog Object & Principal Identity

**Status:** Accepted — Phase 009 Group 02

Unity Catalog three-level names, metastore/workspace/account identifiers and Databricks principal identifiers are source-local identity evidence. They can support current platform object/principal identity within their documented scope.

They do not by themselves establish ecosystem Entity Identity across rename, delete/recreate, repository, Collibra, Immuta or historical replacement boundaries.
