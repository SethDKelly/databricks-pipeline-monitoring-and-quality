# INTG-031 — Technical Schema, Comment & Business-Definition Separation

**Status:** Accepted — Phase 009 Group 02

Unity Catalog schema/object metadata and comments can provide current technical/contextual assertions. Collibra can provide business-governance assets/attributes when configured for that purpose.

AI-generated or human-entered comments remain assertions whose authority depends on governance, not generation mechanism. Declared technical metadata remains separate from realized schema Observation and compatibility Assessment.
