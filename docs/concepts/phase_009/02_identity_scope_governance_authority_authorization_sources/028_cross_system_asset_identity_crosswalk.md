# INTG-028 — Cross-System Asset Identity Crosswalk

**Status:** Accepted — Phase 009 Group 02

A crosswalk may associate Unity Catalog objects, Collibra assets, repositories/components and Immuta data sources only through explicit identifiers or governed mapping relations whose source, scope, effective time and correction history are known.

Name equality, path similarity, schema similarity or synchronization timing is insufficient. Missing crosswalk evidence yields unresolved identity rather than guessed equivalence.
