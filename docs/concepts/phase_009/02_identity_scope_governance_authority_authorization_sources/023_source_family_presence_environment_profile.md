# INTG-023 — Source-Family Presence & Environment Profile

**Status:** Accepted — Phase 009 Group 02

A governance capability decision binds the exact deployed source family, product/edition/version context, enabled feature set and tenant/account/workspace scope. Optional products such as Collibra or Immuta may be absent.

Absence of an optional source is an integration condition, not evidence that the corresponding governance proposition is false, unrestricted, unclassified or unowned.
