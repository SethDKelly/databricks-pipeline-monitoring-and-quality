# INTG-032 — Responsibility Assignment Source Semantics

**Status:** Accepted — Phase 009 Group 02

Collibra Responsibilities directly express resource-role assignments and inheritance and are a strong candidate source for governed business/stewardship responsibility when the organization designates those roles accordingly.

Unity Catalog object owner means platform ownership/privilege-management capability; GitHub CODEOWNERS means code-review responsibility. Neither becomes general business ownership or accountability by convenience.
