# INTG-029 — Monitoring Scope Declarative Source

**Status:** Accepted — Phase 009 Group 02

No evaluated vendor surface natively owns the framework's Monitoring Scope proposition.

A repository configuration/custom property, Collibra attribute or other field may become a Monitoring Scope assertion only when the framework explicitly governs its vocabulary, subject binding, Assertion Authority, effective time and history. Collibra operating-model `scope` is not Monitoring Scope by name similarity.
