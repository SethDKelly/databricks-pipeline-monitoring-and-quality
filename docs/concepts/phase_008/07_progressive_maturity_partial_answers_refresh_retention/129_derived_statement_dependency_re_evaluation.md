# EXPL-129 — Derived Statement Dependency Re-Evaluation

**Status:** Accepted — Phase 008 Group 07

Every Group 02 derived statement retains the identities of its material source propositions and accepted join rule so dependent refresh can be evaluated explicitly.

A change in one dependency does not automatically invalidate or change the derived conclusion; the join must be re-evaluated for the exact proposition.

Unchanged dependencies need not be regenerated merely because another sibling statement changed.
