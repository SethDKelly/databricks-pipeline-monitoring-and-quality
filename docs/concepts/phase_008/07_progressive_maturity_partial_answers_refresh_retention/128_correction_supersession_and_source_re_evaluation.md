# EXPL-128 — Correction, Supersession & Source Re-Evaluation

**Status:** Accepted — Phase 008 Group 07

Source correction/supersession can require current re-evaluation of directly projected and dependent derived statements.

The corrected current interpretation links back to the prior basis/state rather than rewriting it. A correction timestamp is not substituted for the original event/effective time or knowledge cut.

If the source correction does not materially affect a statement, that statement remains unchanged.
