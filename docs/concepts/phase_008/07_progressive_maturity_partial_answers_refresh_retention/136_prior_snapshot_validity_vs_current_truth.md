# EXPL-136 — Prior Snapshot Validity ≠ Current Truth

**Status:** Accepted — Phase 008 Group 07

A prior Explanation can be historically authentic communication even when a later source correction, evidence arrival or authorization change makes it unsuitable as the current answer.

Conversely, a current answer does not retroactively prove the earlier communication was unreasonable, false, authorized or unauthorized without evaluating the earlier knowledge/authorization context.

Historical judgment belongs to the exact time/context proposition, not to recency bias.
