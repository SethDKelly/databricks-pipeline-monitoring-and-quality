# EXPL-133 — Question/Scope Change vs Refresh Identity

**Status:** Accepted — Phase 008 Group 07

A refresh continues the same Explanation lineage only when it answers materially the same bounded request/subquestion set and temporal perspective, allowing normal source/basis/projection evolution.

A materially different subject, requested conclusion, event window, knowledge cut, population, use/profile or other proposition-defining scope creates a distinct question/Explanation lineage or explicitly linked comparison rather than silently mutating the original request.
