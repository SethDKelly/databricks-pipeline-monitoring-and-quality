# Phase 008 Group 05 — Uncertainty, Conflict, Negative Claims & Epistemic Language

**Status:** Next — not started

## Goal

Refine precise Explanation language for unknown, conflicting, unavailable, restricted, insufficient, stale, non-comparable, not-applicable, negative-evidence and competing-claim states without inventing a universal confidence score or reassuring narrative completion.

## Accepted input

Consumes **EXPL-001–EXPL-080**. Group 04 supplies independently bounded Investigation, Causal Claim, Impact, Safeguard, Gate and governance statements with their source status, basis, limitations, negative-evidence burden and temporal/authority context.

## Primary questions

- How should `unknown`, `unavailable`, `insufficient`, `conflicting`, `restricted`, `stale`, `not applicable`, `not evidenced`, `not exposed`, `rejected`, and similar states be worded without conflation?
- How should positive and negative conclusions expose their different evidence burdens?
- How should competing claims/conflicts be summarized without false winner selection?
- How should safe uncertainty language remain useful without inventing numeric confidence/probability?
- How should absence-of-evidence be distinguished from evidence-of-absence across health, execution, causality, Impact and controls?

## Boundary

Group 05 changes communication semantics, not source truth. It may not invent confidence scores, probabilities, global completeness states, hidden conflict resolution, strong negatives, or causal rankings.
