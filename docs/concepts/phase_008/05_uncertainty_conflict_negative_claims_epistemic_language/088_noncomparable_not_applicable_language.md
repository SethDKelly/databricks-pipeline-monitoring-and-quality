# EXPL-088 — Non-Comparable versus Not-Applicable Language

**Status:** Accepted — Phase 008 Group 05

## Requirement

Preserve `non-comparable`/insufficient reference context separately from `not applicable`.

`Non-comparable` means the requested comparison cannot validly support the proposition under the governing dimensions/reference. `Not applicable` means the criterion/question component genuinely does not apply under the governing semantics.

Neither state is a clean pass, failure, zero, or missing-evidence synonym.
