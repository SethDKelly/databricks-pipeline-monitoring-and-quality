# EXPL-095 — Governance, Authority and Authorization Language

**Status:** Accepted — Phase 008 Group 05

## Requirement

Governance uncertainty must remain target-specific.

Missing Responsibility Assignment is `unknown`, not `unassigned`; missing Classification is `unknown`, not non-sensitive; missing Policy Context is unknown/incomplete, not unrestricted; unknown Assertion Authority does not make an available source authoritative; unknown Capability Authorization is not permission.

Conflicting standing/authorization remains conflict unless an accepted resolver applies.
