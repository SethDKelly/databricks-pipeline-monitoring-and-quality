# EXPL-092 — Causal Epistemic Language

**Status:** Accepted — Phase 008 Group 05

## Requirement

Render Causal Claim states using their accepted vocabulary and role: `proposed`, `supported`, `weakened`, `unresolved`, `rejected`, `confirmed`, together with contributor/enabler/trigger/prevention/material-influence semantics when relevant.

`Supported` is not `likely confirmed`; `unresolved` is not `weakly false`; `rejected` requires its own contradiction/exclusion burden; `confirmed` remains REF-017 + AUTH-034 governed.

Multiple claims retain independent states.
