# EXPL-030 — Execution Occurrence & Instance Question

**Status:** Accepted — Phase 008 Group 03

## Requirement

`Did it run?` asks whether an applicable **Execution History** instance is evidence-established for the exact subject/opportunity/scope/time.

Preserve:

**expected work ≠ execution opportunity ≠ Gate state ≠ actual execution instance**.

## Answer semantics

- an established execution instance supports a bounded positive run-occurrence statement;
- scheduled/expected work alone does not support `it ran`;
- Gate ADMIT does not support `it ran`;
- missing telemetry does not support `it did not run`;
- a strong `no run` answer requires the accepted opportunity/coverage burden.

Lifecycle completeness and success are separate EXPL-031 propositions.
