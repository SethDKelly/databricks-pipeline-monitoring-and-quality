# EXPL-034 — Health Dimension, Profile & Composite Question

**Status:** Accepted — Phase 008 Group 03

## Requirement

`Is it healthy?` must resolve to a bounded **Assessment** proposition: subject, dimension or explicit composite profile, use/context, evaluation window/cycle, and temporal perspective.

## Rules

- no intrinsic universal asset-health state is created;
- dimension-specific results may differ legitimately;
- different explicit consumer/use profiles may produce different bounded composite results;
- component disagreement/unavailability/conflict is preserved according to HLTH-055–HLTH-058;
- one healthy dimension does not make siblings healthy;
- Criticality/severity/presentation priority do not manufacture health truth.

Where no profile/dimension can be resolved, the answer remains ambiguous rather than inventing a default global health score.
