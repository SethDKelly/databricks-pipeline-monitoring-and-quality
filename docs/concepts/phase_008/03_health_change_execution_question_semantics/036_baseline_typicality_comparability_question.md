# EXPL-036 — Baseline, Typicality & Statistical Comparability Question

**Status:** Accepted — Phase 008 Group 03

## Requirement

Questions such as `is this normal?`, `is this unusual?`, `can we compare this to before?`, or `how does this compare to baseline?` resolve to Baseline/comparability/descriptive Assessment semantics, not automatically normative health.

## Rules

- available history ≠ eligible comparable reference;
- `typical/unusual relative to Baseline` ≠ `meets/violates Expectation`;
- non-comparable/insufficient/ambiguous reference remains explicit;
- structural/semantic regime changes may require segmented/new reference state;
- newest/largest Baseline has no hidden precedence;
- repeated abnormal values becoming descriptively typical does not make them acceptable.

No statistical distance is converted into universal health severity.
