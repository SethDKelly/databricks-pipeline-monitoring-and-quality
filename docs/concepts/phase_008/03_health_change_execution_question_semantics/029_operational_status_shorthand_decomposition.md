# EXPL-029 — Operational Status Shorthand Decomposition

**Status:** Accepted — Phase 008 Group 03

## Requirement

Business shorthand such as `good`, `healthy`, `current`, `ran`, `succeeded`, `updated`, `live`, or `fixed` must resolve to one or more accepted source-owned propositions before Explanation answers it.

A shorthand request may decompose into independent subquestions for execution occurrence, lifecycle outcome, output existence, current-cycle qualification, freshness, dimension-specific/composite health, realized Change, Deployment activation, or another accepted proposition.

## Rules

- conversational shorthand does not create a universal asset status;
- the narrowest material interpretation supported by the question context is preferred;
- materially different interpretations remain explicit or are answered as separate subquestions;
- one resolved interpretation does not strengthen another;
- question convenience never changes the underlying HLTH/OPS evidence burden.

## Boundary

Explanation translates shorthand; it does not own operational state.
