# Phase 008 Group 02 — Answer Structure, Statement Selection & Basis Traceability

**Status:** Next — not started

## Goal

Refine how a bounded question from Group 01 becomes an evidence-grounded Explanation composed of material statements with explicit source ownership, epistemic type and internal basis traceability.

## Accepted input

Consumes **EXPL-001–EXPL-012** plus the accepted Explanation concept and SYN-030/SYN-031 authorization/projection semantics.

## Primary questions

- What is the identity of a material answer statement?
- Which statements are direct projections of one concept and which are derived cross-concept conclusions?
- How is each material statement linked to supporting/contradicting basis?
- What can a summary omit without changing meaning or epistemic state?
- How do headline, detail and basis-inspection views remain mutually consistent?
- How should multiple independent propositions coexist without creating one synthetic global status?

## Boundary

Do not select UI, citation rendering, template/LLM architecture, retrieval technology or persistence model.
