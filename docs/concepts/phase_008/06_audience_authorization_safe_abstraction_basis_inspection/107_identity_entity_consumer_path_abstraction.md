# EXPL-107 — Identity, Entity, Consumer & Path Abstraction

**Status:** Accepted — Phase 008 Group 06

## Requirement

Restricted entity, person, team, consumer, path or environment identity may be replaced only by an authorized alias/generalization that preserves the material proposition.

`A restricted upstream dependency is a supported contributor` may be valid when exact identity is hidden; `an upstream system caused the incident` is not equivalent if causal status was merely supported.

Alias/generalization must not merge materially distinct subjects when that would change scope, coverage, responsibility, exposure or causality.
