## Four distinct explanatory views

Historical/comparative Explanation preserves views that may legitimately disagree:

1. **Historical source state** — source-owned facts/actions/results effective for the historical proposition.
2. **As-known-at-cut Explanation** — what could be concluded using evidence available by knowledge cutoff `K`.
3. **Actual retained communication** — what was actually communicated for a historical audience/context, when retained.
4. **Current retrospective Explanation** — what is concluded now about the historical proposition using later accepted evidence/corrections.

Current authorized projection applies separately to whichever internal view is requested. It is a disclosure layer, not a fifth truth state.

## Durable comparison rules

- each comparison side independently binds proposition, subject/scope, event/effective window and knowledge perspective;
- event/effective time, knowledge cut and communication time remain independent;
- historical source truth can exist while remaining unknown at an earlier knowledge cut;
- retained prior communication and reconstructed `what was explainable then` are not interchangeable;
- current retrospective interpretation never implies later evidence was known earlier;
- current requester authorization governs present disclosure of historical views but does not rewrite historical actor authorization;
- same-proposition comparison requires equivalent material subject/predicate/scope/event target;
- a materially changed proposition is not represented as one proposition's status change;
- Explanation diffs distinguish source/status, evidence/basis, knowledge-cut, derivation, scope, materiality, authorization/detail, presentation and retained-versus-reconstructed changes;
- `the answer changed` is not a universal truth or causal explanation;
- more visible/more detailed does not mean more true or more supported;
- statement removal does not by itself mean false/retracted/resolved/nonexistent;
- historical unknown/not-evidenced/not-recorded/unavailable/restricted and strong negative remain distinct;
- later resolution of an unknown does not make the earlier unknown historically invalid;
- health/change/execution, causal/Impact and control/governance comparisons preserve their source-domain boundaries;
- correction/supersession changes current preferred interpretation without rewriting prior state/knowledge/communication;
- an authentic historical answer may be unsuitable for current use without becoming fictitious;
- multi-cut progression remains proposition specific and creates no maturity/confidence/completeness score;
- `why did this Explanation change?` may use descriptive delta reasons, but any domain causal proposition still requires Causal Claim semantics.
