# EXPL-148 — Explanation Diff Taxonomy

**Status:** Accepted — Phase 008 Group 08

Comparative Explanation classifies material deltas rather than flattening them into `the answer changed`.

At minimum distinguish:

- source truth/result/status change;
- evidence/basis availability or sufficiency change;
- knowledge-cut change;
- accepted derivation/join re-evaluation;
- proposition/scope change;
- question-relative materiality change;
- authorization/visible-detail change;
- presentation-only change;
- retained-versus-reconstructed-view difference.

Delta classification is descriptive and creates no truth, cause or maturity score.
