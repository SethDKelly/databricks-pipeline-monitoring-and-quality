# EXPL-147 — Comparable Statement Identity across Views

**Status:** Accepted — Phase 008 Group 08

A statement can be compared as the same proposition only when its material subject, predicate/conclusion, scope and event/effective target are equivalent.

Knowledge cut, visible detail and communication time may differ while preserving proposition identity; they are comparison dimensions rather than automatic new propositions.

If material subject/scope/predicate changes, the comparison must identify a proposition change rather than report a status transition for one proposition.
