# EXPL-142 — Temporal Coordinate Set & Perspective Labels

**Status:** Accepted — Phase 008 Group 08

Historical/comparative Explanation preserves independent coordinates for:

- event/effective time or window `T`;
- recorded/knowledge cut `K`;
- composition/communication time where material;
- current disclosure time/authorization context.

A comparison must label materially different perspectives such as `as known by K1`, `as known by K2`, `retrospective now`, or `actually communicated at C1`. No coordinate silently substitutes for another.
