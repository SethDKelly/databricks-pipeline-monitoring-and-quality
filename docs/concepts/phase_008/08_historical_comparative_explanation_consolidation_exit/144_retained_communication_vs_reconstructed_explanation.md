# EXPL-144 — Retained Communication vs Reconstructed Explanation

**Status:** Accepted — Phase 008 Group 08

A retained Explanation snapshot is evidence of what was actually communicated for its bound audience/context/time.

A later `composeAt` reconstruction is a present derivation using the selected historical cut and current projection rules. It may approximate what was explainable then, but cannot be labeled the exact prior communication unless retained communication evidence establishes that.

Missing retained communication remains missing.
