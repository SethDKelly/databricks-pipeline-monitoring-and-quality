# EXPL-158 — Reason-for-Answer-Difference Boundary

**Status:** Accepted — Phase 008 Group 08

`Why did the answer change?` first asks for a descriptive Explanation-delta reason, not necessarily a domain causal claim.

It may be answered with evidence such as `later consumer telemetry became available`, `source correction superseded an earlier record`, `authorization now permits more detail`, or `the question scope changed`.

If the requested statement asserts that one event caused another domain outcome, normal Causal Claim semantics still apply. Explanation-delta metadata cannot bypass REF/AUTH causal requirements.
