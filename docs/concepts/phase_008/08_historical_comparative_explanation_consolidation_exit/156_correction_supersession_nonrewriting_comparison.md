# EXPL-156 — Correction, Supersession & Non-Rewriting Comparison

**Status:** Accepted — Phase 008 Group 08

Corrections/supersessions can change current retrospective interpretation and current preferred Explanation without editing prior source records, knowledge-cut reconstructions or retained communications.

A comparison may state that an earlier conclusion is now superseded or no longer suitable for present use while preserving whether it was justified by the evidence/authority available then.

Supersession of an Explanation projection is not automatically supersession of source truth.
