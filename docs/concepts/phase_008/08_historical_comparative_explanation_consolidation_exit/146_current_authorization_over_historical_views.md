# EXPL-146 — Current Authorization over Historical Views

**Status:** Accepted — Phase 008 Group 08

Present disclosure of any historical/as-known/retained/retrospective view is governed by the current requester's applicable Capability Authorization and disclosure rules.

Historical actor access does not grant current access. Current broader access does not prove the requester historically had access, and current revocation does not erase the fact that a prior communication occurred.

Current projection may reduce visible detail but cannot strengthen the underlying historical proposition.
