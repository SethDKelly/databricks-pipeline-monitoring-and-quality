# EXPL-153 — Comparative Health, Change & Execution Semantics

**Status:** Accepted — Phase 008 Group 08

Comparisons across health/change/execution retain Group 03 boundaries.

Run occurrence, lifecycle outcome, output existence, freshness/currentness, dimension/profile health, structure, compatibility, comparability, Change Intent, Deployment/activation, realized Change, run-specific version use and timing are compared as separate propositions.

`Health improved`, `deployment fixed it`, or `new version ran` is valid only when the exact underlying propositions and, where causal, Causal Claim basis support that wording.
