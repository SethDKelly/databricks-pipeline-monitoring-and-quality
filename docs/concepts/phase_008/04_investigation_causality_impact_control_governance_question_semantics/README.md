Refine `why`, root-cause, downstream Impact/exposure, Safeguard/Gate, responsibility, policy/meaning, authority and capability questions while preserving the accepted truth ownership and evidence/authority boundaries of Phases 004–007.

Group 04 accepts **EXPL-050–EXPL-080** and scenario suite **ICG04-01–ICG04-48**.

- **EXPL-080** — Group 05 handoff.

## Durable rules

- Investigation lead/localization ≠ Causal Claim;
- first observed/earliest evidenced/boundary/consumer effect ≠ root cause;
- `root cause` wording does not force a singular winner;
- causal role/status survives explanation and `confirmed` remains REF-017 + AUTH-034 governed;
- lack of support ≠ causal rejection/exclusion;
- candidate/reachable ≠ opportunity ≠ exposure ≠ effect ≠ consequence ≠ causal attribution;
- `affected` must resolve to the intended Impact layer;
- `none/all/only` Impact claims require bounded population/coverage;
- Safeguard proposal/configuration/authorization/request ≠ enforcement;
- Safeguard active + not exposed ≠ prevented exposure;
- Safeguard release ≠ recovery;
- readiness ≠ Gate decision ≠ Gate enforcement ≠ execution;
- HOLD ≠ failed execution; ADMIT ≠ run;
- override/fallback/escalation/degraded control preserve their distinct semantics;
- Execution Gate ≠ Propagation Safeguard;
- control overlap/timing ≠ control-effect causality;
- Responsibility Assignment ≠ fault/cause/authority/permission;
- Semantic Definition ≠ realized state/health/policy/authorization;
- Classification ≠ Policy Context/authorization/Impact/compliance;
- Policy Context ≠ enforcement/legal interpretation/compliance;
- Capability Authorization ≠ responsibility/assertion authority/action success;
- Assertion Authority ≠ factual truth/evidence sufficiency/permission/enforcement;
- no universal RCA/Impact/control-effectiveness/governance-confidence score is accepted.
