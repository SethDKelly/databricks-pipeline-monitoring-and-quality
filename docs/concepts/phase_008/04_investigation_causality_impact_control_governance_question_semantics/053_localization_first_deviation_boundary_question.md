# EXPL-053 — Localization, First-Deviation & Boundary Question

**Status:** Accepted — Phase 008 Group 04

## Requirement

Questions such as `where did it first go wrong?` must resolve which localization proposition is requested:

- first observed deviation;
- earliest evidenced state change;
- first localized transformation/reconciliation boundary;
- first downstream consumer effect.

Each `first` statement is bounded by searched scope, topology, time/version ordering and evidence coverage.

No localization result is automatically `root cause`.
