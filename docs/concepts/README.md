# Concepts

DMTZ models **24 independently motivated concepts**, each with one current semantic owner in this directory:

Monitoring Scope · Entity Identity · Semantic Definition · Responsibility Assignment · Classification · Policy Context · Expectation · Baseline · Observation · Assessment · Change Intent · Execution History · Deployment · Lineage · Change · Investigation · Causal Claim · Impact · Annotation · Explanation · Propagation Safeguard · Capability Authorization · Execution Gate · Assertion Authority.

Each concept owns a distinct purpose, state, actions, invariants, and ambiguity boundary. Related concepts coordinate through explicit synchronization and cross-cutting contracts rather than sharing an implicit truth model.

Synchronization contracts are maintained under [`../contracts/synchronization/`](../contracts/synchronization/). Exact current ownership and provenance are declared in [`../canonical_knowledge_retrofit/canonical_ownership_inventory.json`](../canonical_knowledge_retrofit/canonical_ownership_inventory.json).

Historical concept development and prior design progression are preserved under [`../history/`](../history/README.md) as provenance only.
