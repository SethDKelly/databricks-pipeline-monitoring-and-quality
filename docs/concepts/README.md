## Durable boundaries preserved through migration

- Assertion Authority ≠ Capability Authorization ≠ evidence sufficiency ≠ enforcement;
- Baseline ≠ Expectation;
- Observation ≠ Assessment;
- Change Intent ≠ Deployment ≠ realized Change;
- execution success ≠ output existence ≠ freshness ≠ data health;
- Lineage/reachability ≠ encounter/exposure ≠ Impact ≠ causality;
- Investigation lead/localization/closure ≠ Causal Claim status/confirmation;
- Gate readiness ≠ decision ≠ enforcement ≠ actual execution;
- Execution Gate ≠ Propagation Safeguard;
- current state ≠ historical/as-known state;
- Explanation/model/search output ≠ independent truth source.

CKR changes owner paths; it does not silently change accepted meaning.
