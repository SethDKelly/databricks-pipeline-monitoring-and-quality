# Group 05 — Downstream Impact, Annotation & Explanation

**Status:** Planned

## Goal

Define how downstream Lineage creates Impact candidates, how evidence refines reachability into exposure/effect/consequence, how human Annotation participates without stealing structured truth, and how authorized Explanation composes the result.

## Planned synchronization questions

- Lineage traversal → Impact candidates;
- execution/consumption evidence → exposure;
- downstream Observation/Assessment/Change → observed effect;
- semantic/criticality/business evidence → consequence context;
- Annotation → contextual support without mutation/confirmation;
- all authorized concept state → evidence-grounded Explanation with statement-to-basis traceability.
