# Group 04 — Lineage, Investigation & Causal Reasoning

**Status:** Planned

## Goal

Define how questions/symptoms create bounded Investigations, how historical typed Lineage discovers evidence candidates, and how competing Causal Claims accumulate support/contradiction without forced root cause.

## Planned synchronization questions

- Assessment/Change/question/realization mismatch → Investigation initiation;
- Investigation scope/time → Lineage/evidence discovery;
- Change Intent, Deployment, Execution History, Observation, Assessment, Change, Lineage → Causal Claim evidence links;
- temporal ordering and contradicting evidence;
- multiple contributors and unresolved closure;
- scope/authorization boundaries during upstream traversal.
