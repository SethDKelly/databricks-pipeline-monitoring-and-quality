# Group 02 — Planned Change & Reference Transition

**Status:** Next review group

## Goal

Define the synchronization chain from registered Change Intent through prospective Expectation/Baseline handling and into evidence that a structural transition actually became active.

## Planned synchronization questions

- Change Intent → explicit prospective Expectation review/establishment/revision without turning anticipated effects into norms automatically.
- Change Intent → prospective Baseline comparability break without ending the old Baseline before realization.
- Change Intent ↔ Deployment realization linkage without treating Deployment success as intended-effect proof.
- Deployment/realized Change evidence → effective activation of the Baseline comparability boundary.
- post-change Observations → eventual empirical Baseline derivation.
- withdrawal/failed activation/rollback/correction behavior.

## Primary scenarios

E-02 planned valid structural change, E-03 planned change with unintended violation, E-04 unregistered change, E-06 deployment-correlated shift, E-10 historical correction.

## Exit direction

Advance when planned context can change future reference applicability without manufacturing observations/history or suppressing independent health violations.
