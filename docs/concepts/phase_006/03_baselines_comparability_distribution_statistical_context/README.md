# Phase 006 Group 03 — Baselines, Comparability, Distribution & Statistical Context

**Status:** Planned — not yet started

## Goal

Define descriptive reference behavior and empirical comparability without turning Baselines into normative Expectations or introducing an opaque anomaly/confidence score.

## Review scope

- Baseline reference population/window/cohort semantics;
- rolling versus fixed/reference-period behavior;
- comparable grain/schema/definition requirements;
- seasonality, cadence and cohort segmentation;
- low-volume/sample-size limitations;
- exact versus approximate/sampled observations;
- numeric/categorical distribution comparison;
- selected quantiles/category-share/drift semantics;
- structural/semantic changes that break or weaken comparability;
- insufficient/non-comparable/unknown reference state;
- whether historical reference needs replacement, segmentation or bounded reset after change.

## Accepted handoff

HLTH-001–HLTH-008 provide exact metric-definition/version, measurement binding, applicability and provenance. AUTH-020 may govern intended Baseline use, but authority cannot manufacture empirical comparability.

## Boundaries

Do not promote typicality to health. Do not define threshold severity/waiver semantics yet. Do not select anomaly algorithms, statistical libraries, storage or compute architecture.

**Group 03 has not started.**
