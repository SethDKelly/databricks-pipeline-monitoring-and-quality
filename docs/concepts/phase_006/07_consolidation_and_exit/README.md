# Phase 006 Group 07 — Consolidation / Exit Review

**Status:** Planned — not yet started

## Goal

Replay Phase 006 Groups 01–06 across representative ecosystem scenarios and determine whether the health/metric/schema/statistical model composes without a new concept, universal score, false pass, blind propagation, hidden authority or technical architecture.

## Exit checks

- metric definitions/Observations/Assessments remain distinct;
- semantic applicability, profile selection, source support, availability and health outcome remain distinct;
- structural/schema compatibility remains consumer/context specific;
- Baseline comparability remains evidence-driven and non-normative by itself;
- threshold/margin/waiver semantics preserve underlying evidence and normative conflict;
- transformation reconciliation is explicit and does not recursively propagate metrics;
- composite health does not hide failed/conflicting/unknown/unavailable dimensions;
- technical/business views remain projections over one truth;
- control-eligible conditions remain evidence-fresh/mature enough before readiness use and do not become gate decisions/enforcement;
- passive monitoring remains non-blocking for ungated production;
- no Databricks/DQX/Metric View/GitHub Actions/Unity Catalog/storage/streaming/scheduler architecture is selected merely to close the phase.

## Representative replay areas

- A+B→C row-count/join-key degradation;
- schema rename/drop/type/grain changes and selective Baseline invalidation;
- seasonal population changes versus explicit thresholds;
- bounded waivers during migrations;
- low-volume and approximate metrics;
- profile anti-bloat and diagnostic escalation;
- multiple upstream metric contributors;
- technical versus business health projection;
- unavailable/pending metrics and composite health;
- AUTH-023 control-eligible condition with stale/unavailable evidence;
- historical replay after metric-definition/schema/Baseline changes.
