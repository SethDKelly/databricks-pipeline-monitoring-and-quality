# Phase 006 Group 04 — Expectations, Thresholds, Margins, Waivers & Assessment Semantics

**Status:** Planned — not yet started

## Goal

Define how applicable Observations and Baselines are interpreted against explicit normative Expectations while preserving conflict, bounded exceptions and underlying measurement truth.

## Review scope

- hard criteria versus warning/failure bands;
- absolute, relative and asymmetric thresholds/margins;
- normative Expectation versus descriptive Baseline comparison;
- threshold evaluation with low-volume/approximate/uncertain evidence;
- simultaneously valid rules in different contexts versus normative conflict;
- bounded waiver/exception/suspension presentation;
- dimension-level Assessment status vocabulary;
- interaction of `pass/fail/warning/degraded/atypical/unknown/conflicting/unavailable/non-applicable` without conflation;
- severity versus health state;
- evidence suitability required before an Assessment can be produced.

## Accepted handoff

Phase 005 AUTH-016–AUTH-023 determines who can establish/revise/waive/retire normative rules. Groups 01–03 provide metric semantics, applicability and Baseline comparability. Group 04 defines functional evaluation, not authority.

## Boundaries

Waivers do not create false clean passes. Strictest/business/technical/latest/highest-severity does not silently resolve normative conflict. Do not define overall/composite health yet.
