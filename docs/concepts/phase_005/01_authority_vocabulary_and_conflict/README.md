# Phase 005 Group 01 — Authority Vocabulary, Source Assertions & Conflict Resolution

**Status:** First review group — not yet started

## Goal

Define the shared authority vocabulary and conflict/supersession semantics that later Phase 005 groups will apply to specific governance, normative, capability, control, and disclosure categories.

## Primary review questions

- source assertion versus authoritative assertion versus advisory/enriching assertion;
- category/subject/environment/context/effective-time scoped authority;
- provenance and authority-rule validity;
- source/actor conflict without hidden majority/recency precedence;
- correction and supersession without deleting historical assertions;
- unknown/unresolved authority state;
- relationship between Phase 005 authority semantics and Phase 009 source-specific contracts.

## Boundaries

Do not select a universal authoritative vendor/source, IAM implementation, metric model, or architecture. Authority does not change Phase 004 evidence sufficiency.

## Exit direction

Group 01 exits when later groups can apply a stable common authority/conflict vocabulary without inventing their own precedence semantics.
