# Phase 005 Group 02 — Semantic, Responsibility, Classification, Policy & Criticality Governance

**Status:** Planned — not yet started

## Goal

Apply Group 01 authority semantics to descriptive and governance context without turning those assertions into access, normative health, control, or compliance truth.

## Primary review questions

- authority for Semantic Definition facets;
- Responsibility Assignment and stewardship authority;
- Classification and Policy Context authority by subject/context/time;
- criticality authority and local/contextual overrides;
- conflict, correction, supersession, and historical governance state;
- role of Databricks/Unity Catalog, Collibra, Immuta, Git sources, and human stewards without assuming universal authority.

## Boundaries

Descriptive/governance authority does not automatically grant Capability Authorization, metric/Expectation authority, gate/safeguard authority, or causal-confirmation authority. Policy applicability is not compliance proof.

## Exit direction

Group 02 exits when the project can resolve or preserve conflicts in semantic/governance context using Group 01 rules while keeping other authority categories independent.
