- current topology is never projected backward as historical topology;
- planned topology/change is not treated as realized state;

- control-induced delay/staleness/non-delivery remains observable without being automatically classified as defect/cause;
- Phase 005 authority/authorization/disclosure and Phase 006 health/suitability semantics remain intact;
