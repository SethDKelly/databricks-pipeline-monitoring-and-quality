# OPS-123 — Historical Gate Replay, Ownership & Group 09 Handoff

**Status:** Accepted — Phase 007 Group 08

## Purpose

Define the final Gate truth boundary and the evidence Group 09 must replay.

## Ownership

**Execution Gate owns:**

- configuration/profile applicability;
- exact opportunity-specific criterion reference and decision/action history;
- decision basis including normal, override and fallback-applied context;
- decision delivery/acceptance/enforcement evidence linked to the Gate proposition;
- hold/admit/override/cancel/expiry/supersession history;
- Gate-specific degraded-control/fallback provenance.

**Other concepts own:**

- readiness/suitability truth — Assessment/Phase 006 semantics;
- actual execution/run/version — Execution History;
- authorization — Capability Authorization;
- publication/consumption protection — Propagation Safeguard;
- downstream encounter/effect/consequence — Impact/source concepts;
- broader control-effect attribution — Causal Claim.

## Historical replay

Reconstruct separately:

- then-applicable Gate/profile/prerequisite set;
- evidence/readiness known at decision cut;
- actual decision and authority;
- delivery/acceptance/enforcement known then;
- actual execution/outcome;
- later evidence/corrections and current retrospective interpretation.

Late telemetry can revise retrospective enforcement/causal understanding but never rewrite the actual historical decision or execution.

## Group 09 handoff

Group 09 consumes OPS-001–OPS-123 and should add no new OPS contract unless cross-group replay exposes a genuine semantic gap.
