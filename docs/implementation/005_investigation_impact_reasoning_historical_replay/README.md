# Implementation 005 — Investigation, Impact Reasoning & Historical Replay

**Status:** PLANNED

## Objective

Build the deterministic reasoning layer over canonical evidence: Investigation lifecycle, localization/leads, competing Causal Claims, exact graph-shaped retrieval, historical/as-known replay, Statement IR / Answer IR and `inspectBasis` internal resolution.

No LLM is required for acceptance.

## Entry gate

- 004 produces stable runtime/health/Lineage/Impact evidence;
- 002 authority/authorization interfaces executable;
- historical evidence availability-by-K proven by persistence.

## Group plan

### 005-A — Investigation / Lead Lifecycle

Build canonical Investigation boundaries, lead/localization provenance, workflow history, annotations and explicit unresolved closure.

### 005-B — Causal Claim State Machine

Implement proposed/supported/weakened/unresolved/rejected/confirmed states, evidence relations, alternative review and confirmation gates using REF-017 + AUTH-034 semantics.

### 005-C — Exact Retrieval & Typed Reasoning Graph Projection

Build Delta-backed/rebuildable graph-shaped projection/traversal for exact identities, temporal relations and evidence links. Specialized graph storage remains optional.

### 005-D — Deterministic Evidence / Coverage / Authority Rules

Implement proposition-relative evidence suitability, contradiction, exclusion/negative coverage, authority and status evaluation.

### 005-E — Historical / As-Known Replay

Build replay using canonical bitemporal/availability-by-K journals and governing revisions. Distinguish actual retained historical state from reconstruction.

### 005-F — Statement IR / Answer IR Composition

Compose question-bound statements, supporting/contradicting/unknown basis, limitations, temporal perspective, causal/Impact statuses and audience-neutral internal IR.

### 005-G — Basis Resolution / Explanation Snapshot Foundation

Implement exact internal statement-to-basis resolution and retained communication identity/snapshot foundation where product policy promises authentic historical communication.

### 005-H — Consolidation / Exit

Prove multiple-contributor, unresolved-cause, late-evidence correction, historical-as-known and causal-confirmation-boundary scenarios.

## Exit result

DMTZ can deterministically explain what happened, what changed, what evidence supports or contradicts candidate causes, what downstream impact is evidenced and what was known at a selected historical cut—without a model inventing truth.
