**Status:** PLANNED / OPTIONAL — execute only when Execution Gate and/or Propagation Safeguard are a product commitment

## Objective

Realize the frozen Group 07 active-control architecture without turning controls into passive truth or collapsing readiness, decision, enforcement, execution, prevention and recovery.

- passive evidence/governance/reasoning platform stable through at least 007/008;
- exact target control opportunities/adapters selected;
- Capability Authorization for control actions executable;
- SC-06 latency/failure/resource requirements defined.

## Group plan

### 010-F — Prevention / Alternate-Path / Release / Recovery

Implement exposure-opportunity and alternate-path inventory/coverage, REF-028 prevention evaluation, extension/expiry/release and independent recovery.

### 010-G — Control Security / SC-06 Operations

Replay Group 07 control scenarios as executable integration/E2E tests, including bypass, stale decisions, adapter failure, enforcement contradiction, no-opportunity/no-prevention and historical replay.

## Exit result
