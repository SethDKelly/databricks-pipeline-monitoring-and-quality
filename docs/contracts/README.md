# Contracts

Current DMTZ domain and cross-cutting contracts are organized by responsibility:

- `synchronization/` — SYN-001–SYN-035
- `evidence-time-causality/` — REF-001–REF-030
- `health-quality-timing/` — HLTH-001–HLTH-066
- `operations/` — OPS-001–OPS-123
- `integration/` — INTG-001–INTG-270

These contracts coordinate concept behavior while preserving separate ownership for evidence, authority, health, operations, integration, causality, timing, and control semantics.

Use [`../canonical_knowledge_retrofit/canonical_ownership_inventory.json`](../canonical_knowledge_retrofit/canonical_ownership_inventory.json) or the stable-ID resolver for exact current ownership. Historical contract development is preserved under [`../history/`](../history/README.md).
