# Experience and Explanation

Current DMTZ experience contracts define how questions are scoped, how evidence and epistemic state are communicated, how explanations vary by audience/authorization, and how historical or progressively maturing answers remain traceable.

EXPL-001–EXPL-160 are organized across:

- `question-scope-temporal.md` — EXPL-001–012
- `answer-structure-traceability.md` — EXPL-013–028
- `health-change-execution-questions.md` — EXPL-029–049
- `investigation-impact-control-governance-questions.md` — EXPL-050–080
- `epistemic-language.md` — EXPL-081–100
- `audience-authorization-safe-abstraction.md` — EXPL-101–120
- `progressive-maturity-retention.md` — EXPL-121–140
- `historical-comparative-explanation.md` — EXPL-141–160

Explanation is a bounded, source-faithful, basis-traceable, epistemically calibrated, and currently authorized communication projection. It does not create separate Question, Answer, confidence, maturity, RCA, Impact-summary, control-effectiveness, audience-truth, or historical-answer truth owners.
