## Documentation discipline

- Concepts/synchronizations/refinements remain implementation-neutral.
- Phase 004 `REF-###` defines evidence/time/causal/control standards; Phase 005 `AUTH-###` defines authority/governance/capability/disclosure standards.
- Preserve historical rationale; add/supersede rather than silently rewrite.
- Synchronization/refinement order never becomes source authority or causation.
- Evidence sufficiency is conclusion-relative; applicability, coverage, corroboration/conflict, and sufficiency remain separate.
- Negative/absence/exclusion conclusions require adequate opportunity-to-observe plus bounded coverage.
- Missing/restricted/unavailable evidence is not a negative fact.
- Duplicated/common-source telemetry is not independent corroboration merely because it appears in several systems.
- Event/effective time, source availability, framework knowledge, and derived evaluation time remain distinct.
- Monitoring/reasoning results may mature progressively without status inflation.
- Causal confirmation requires evidence sufficiency plus independently resolved authority.
- Exposure/readiness/gate/safeguard evidence layers remain separate.
- Assertion Authority is target/category/facet/context/time scoped; no vendor/source is globally authoritative by default.
- Capability Authorization remains separate from Assertion Authority, Responsibility Assignment, Policy Context, Classification, and Monitoring Scope.
- High-consequence authorization remains separate from actual action/enforcement/outcome.
- Disclosure/Explanation remains a projection over one truth and cannot strengthen underlying status.
- Passive monitoring remains non-blocking/out-of-band by default; Execution Gate remains explicit opt-in active control.
- Phase 006 owns detailed metric/statistical/schema-health/timing semantics and has not started.
- Keep examples synthetic; no real PII/PHI/secrets/production values.
