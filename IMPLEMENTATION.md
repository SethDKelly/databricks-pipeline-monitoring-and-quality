## Coding-agent guidance

- Root [`AGENTS.md`](AGENTS.md) remains the shared repository constitution.
- Completed ADF-A establishes common A1–A4 action classes and human-directed scope.
- Completed ADF-B establishes `knowledge/` as a portable routing projection over canonical authority; OKF lifecycle/trust/provenance metadata does not become DMTZ semantic state.
- `.cursor/rules/*.mdc` remains a scoped Cursor adapter layer rather than a second source of truth.
- ADF-C will now implement thin Cursor/Claude/Codex instruction adapters against the shared ADF-A authority policy and ADF-B knowledge entry point.
- Autonomous task execution, multi-agent delegation/orchestration, unattended merge/deploy and agent-created work allocation are **not** part of the accepted foundation.
