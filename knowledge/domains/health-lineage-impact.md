# Routing

For HLTH-001–HLTH-066 current semantics, use the canonical [health/quality/timing index](../../docs/canonical/contracts/health-quality-timing/README.md). For OPS-001–OPS-123 Lineage/change/execution/Investigation/Impact/Safeguard/Gate semantics, use the canonical [operations index](../../docs/canonical/contracts/operations/README.md). Integration/source behavior in INTG and ARCH runtime implementation remain with their current owners via the ownership inventory until later CKR cutovers.

Critical boundaries: execution success is not health; Lineage does not propagate metric or health status; reachability is not exposure; localization is not cause; Impact consequence is not causal attribution; Safeguard is not Gate; readiness is not Gate decision or enforcement. OKF is routing only.
