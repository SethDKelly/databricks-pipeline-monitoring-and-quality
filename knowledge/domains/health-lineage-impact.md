# Routing

For HLTH-001–HLTH-066 current semantics, use the canonical [health/quality/timing index](../../docs/canonical/contracts/health-quality-timing/README.md). For OPS-001–OPS-123 Lineage/change/execution/Investigation/Impact/Safeguard/Gate semantics, use the canonical [operations index](../../docs/canonical/contracts/operations/README.md). For INTG-001–INTG-270 source capability, runtime evidence, Lineage encounter/exposure and cross-source feasibility, use the canonical [integration index](../../docs/canonical/contracts/integration/README.md). ARCH runtime implementation remains with Phase 010 until CKR-I.

Critical boundaries: execution success is not health; Lineage does not propagate metric or health status; reachability is not encounter/exposure; source availability is not authority; localization is not cause; exposure is not effect/consequence/causal attribution; Safeguard is not Gate; readiness is not Gate decision or enforcement. OKF is routing only.
