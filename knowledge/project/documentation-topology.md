# Use

Use the [DPTN README](../../docs/documentation_topology_normalization/README.md) for live normalization status and [topology authority](../../docs/documentation_topology_normalization/topology_authority.md) for what DPTN may change.

DPTN-A is inventory/planning only. Its [move map](../../docs/documentation_topology_normalization/move_map.json) describes future physical destinations and dependency order; it does not establish current semantic authority.

Current meaning still resolves through the CKR ownership inventory and current canonical owners. Implementation 001-A is blocked until DPTN-G exit acceptance.
